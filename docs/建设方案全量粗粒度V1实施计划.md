# 线上营销智能体平台：建设方案全量粗粒度 V1 实施计划

> 版本：v1.0  
> 日期：2026-09-10  
> 执行策略：先完成建设方案全量能力的粗粒度闭环，再进入专项优化。  
> 计划优先级：如与 `建设文档适配评估与PRD规划.md`、`建设文档分步开发与验收操作手册.md` 的开发顺序冲突，以本文为准。

## 1. 计划目标

本轮不再围绕单个模块持续纵向优化，而是先把建设方案和功能对比表中的全部内容做出一版可运行、可演示、可验收的 V1。

V1 的目标不是达到生产级容量或算法最优，而是确保每项建设内容都具备最小业务闭环：

1. 有真实菜单或业务入口，不以空白页、静态原型冒充完成。
2. 有数据库模型或明确的外部数据契约，数据可创建、查询和追溯。
3. 有后端接口和前端操作，至少跑通一条成功路径与一条失败路径。
4. 有工作空间权限、关键操作审计和统一状态定义。
5. 产生的告警和站内通知统一进入右上角全局告警铃铛，不重复建设模块内通知中心。
6. 有专项测试、基础回归和操作/验收文档。
7. 依赖真实外部平台时，先完成适配器、协议模拟器、样例数据和联调清单；未接真实环境必须标记为“待外部联调”，不能标记为“全部完成”。

### 2.2 V1 粗粒度完成标准

每个功能包必须同时满足以下条件，才可把状态从“开发中”改为“V1 完成”：

- 数据：至少有一套可重复导入或生成的脱敏样例数据。
- 后端：核心接口真实读写数据库，不返回硬编码成功结果。
- 前端：可以从正常菜单进入，并完成核心操作。
- 闭环：输入、处理、结果、历史记录四个环节可追溯。
- 安全：工作空间隔离、权限校验、敏感字段保护和关键操作审计可验证。
- 异常：依赖不可用、参数错误或任务失败时有清晰状态和恢复入口。
- 验证：迁移检查、专项测试、目标前端 ESLint、类型检查、生产构建和浏览器验收通过。
- 文档：操作步骤、验收样例、已知限制、外部联调项和排障经验同步更新。

### 2.3 本轮明确延后的优化

以下工作不是删除，而是在全量 V1 完成后统一进入 V2 优化池：

- 检索评估的基线版本对比、自动回归门禁和高级可视化。
- 推荐、归因、动态阈值和路径规划算法的深度调参。
- 大规模分布式训练、超大数据量压测和生产流量灰度。
- 视觉动效、复杂图表联动和非关键交互细节。
- 尚无外部账号或网络环境时的真实晓搭、IVR、EOP、云翼平台生产联调。

已经完成的检索评估、营销告警、营销运营和质检能力保留；本轮只做建设方案覆盖所需的缺口，不继续做非必要纵向增强。

## 5. 分步实施路线

> 本章的 `Mxx` 是稳定的需求包编号，不代表执行先后；实际开发顺序以 3.2 节优先级表为准。

### M00：需求冻结与全量看板

目标：建立唯一计划和状态口径，停止无边界的单模块追加优化。

交付：

- 本文及 `X01～X38` 追踪表。
- 每项需求使用“待建 / 局部基础 / 开发中 / V1 完成 / 待外部联调”五种状态。
- 每个里程碑建立一份实施任务卡和一份验收文档。
- 新需求必须关联需求编号或新增编号后再开发。

验收：38 项功能和 Word 补充要求均有明确归属，无遗漏、无重复主责。

### M01：共享业务底座与统一约束

目标：给后续模块提供相同的权限、审计、任务、版本、附件和通知规则，避免每个模块各做一套。

V1 范围：

- 复用现有工作空间与 RBAC，定义新模块资源权限。
- 统一异步任务状态、操作日志、版本记录、附件引用和外部适配状态。
- 统一领域事件信封、幂等键、失败原因和重试入口。
- 统一全局告警铃铛接入契约；不新增局部通知中心。
- 建立脱敏样例数据目录和一键初始化命令。

验收：任选一个样例任务可看到发起人、工作空间、状态、执行历史、失败原因、审计记录和全局通知。

### M02：服务助手 V1 收口

对应：X06、X07、X08、X14。

V1 范围：

- 跑通“资料导入 → 索引 → 检索 → 生成 → 合规审核 → 引用/拦截记录”。
- 保留现有检索评估中心作为验收工具，本阶段不继续建设高级基线对比。

验收：使用一份产品资料分别验证正常有引用回答、无知识兜底回答和违规内容拦截。

### M03：指标、预测预警、派单与配置底座 V1

## 6. 执行节奏与状态更新

每次只推进一个里程碑中的一个可验收任务包，建议节奏如下：

1. 开始前：列出本步对应需求编号、现状、改动范围和验收样例。
2. 开发中：后端数据与接口先闭环，再接前端；外部依赖同时建设模拟器。
3. 完成时：运行专项测试与前端门禁，用真实浏览器走一次成功和失败路径。
4. 交付时：更新本文状态、测试文档、操作说明和 `.learnings/`。
5. 用户验收后：进入下一任务包，不在当前模块继续追加非阻塞优化。

状态更新规则：

- “局部基础”表示有可复用代码，但未满足当前需求闭环。
- “V1 完成”表示本地/测试环境闭环与门禁已通过。
- “待外部联调”表示代码、适配器和模拟验收完成，但真实第三方环境尚未验证。
- 外部联调完成后才可改为“已联调”。
