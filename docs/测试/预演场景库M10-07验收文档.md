## 2. 数据模型与状态规则

新增 `RehearsalSceneLibrary` 和 `RehearsalSceneLibraryEvent`，并给 `RehearsalSceneRun` 增加可空 `library` 关联。

场景库状态：

- `DRAFT`：草稿，可继续配置。
- `READY`：可复用，可从库创建场景执行。
- `ARCHIVED`：已归档，保留版本与事件，不参与常规复用。

可见范围：

- `WORKSPACE`：工作空间可用。
- `PRIVATE`：仅创建人可用；V1 先沉淀字段和展示，复杂跨租户/市场权限不在本步展开。

事件动作：

- `CREATED`：创建场景库。
- `CLONED`：克隆版本。
- `PUBLISHED`：发布场景库。
- `ARCHIVED`：归档场景库。
- `RUN_CREATED`：从场景库创建场景执行。

幂等与版本规则：

- 场景库在工作空间内按 `request_id` 幂等。
- 同一 `code + version` 在工作空间内唯一。
- 克隆默认生成下一版本，并继承来源库的剧本、实例、流程模板、数据模型、权限和配置快照。
- 从场景库创建执行会复用库中的剧本快照，同时把 `library_id / library_name / library_version` 写入场景执行摘要。

## 3. 管理接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/scene-library` | 查询预演场景库 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-library` | 创建预演场景库 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/scene-library/{library_id}` | 查看场景库详情、关联、执行和事件 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-library/{library_id}/clone` | 克隆场景库版本 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-library/{library_id}/operate` | 发布或归档场景库 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-library/{library_id}/run` | 从场景库创建场景执行 |

Dashboard 已同步返回 `scene_library_count`、`scene_library_ready_count` 和 `scene_libraries`。预演实例详情已同步返回 `scene_library_count` 和 `scene_libraries`。
