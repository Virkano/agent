# 第十八阶段：转化归因与营销闭环验收文档

## 目标

在既有“触达结果、人工跟进、审批、批次执行”基础上，补齐真实业务结果的确认与归因，区分“有意向”和“已办理”，并将最终结果回写到批次、任务看板和营销复盘中。

## 结果规则

- 只有通过“转化”登记的“确认办理”才会将客户标记为“已办理”；人工跟进或客户编辑不能绕过该登记直接标记。
- “确认流失”会将客户标记为“无意向”，自动移出待跟进队列。
- 每次确认都会新增一条历史记录，不覆盖旧记录。统计和客户列表展示该客户最新的一条结果。
- 可选择归因触达批次；未选择时，系统自动关联客户最近一次执行记录所属的批次。
- 已选择的归因批次必须属于当前任务，且批次快照中包含该客户，防止跨任务或错误归因。
- 已确认办理的客户不能继续登记新的触达结果；如业务状态变化，应通过新的“确认流失”记录更正，历史仍会保留。

## 页面操作

1. 进入“营销任务”并打开“客户名单”。
2. 在目标客户操作列点击“转化”；也可在“触达批次 → 执行与复盘”的客户快照中点击“确认转化”。
3. 选择“确认办理”或“确认流失”。
4. 若为确认办理，填写实际办理的套餐/产品；两种结果都必须填写结果说明。
5. 按需选择归因批次，或保留为空让系统自动识别最近触达批次，点击“确认登记”。
6. 检查客户名单的“转化结果”、批次执行抽屉的“转化归因记录”、任务经营看板的“确认办理 / 流失、转化率”和营销任务复盘中的策略“办理”列。
