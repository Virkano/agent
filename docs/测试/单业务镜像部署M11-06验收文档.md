## 2. 最终部署边界

| 组件 | 部署方式 | 对外端口 |
| --- | --- | --- |
| 管理端与对话端 | 进入业务镜像，由 Django 提供构建后静态资源 | 8080 |
| Django Web | 业务镜像内 Gunicorn | 8080 |
| Celery Worker | 业务镜像内部进程 | 无 |
| 本地向量服务 | 业务镜像内 Gunicorn | 仅 `127.0.0.1:11636` |
| PostgreSQL/pgvector | 用户已有容器或独立实例，环境变量对接 | 不由业务镜像决定 |
| Redis | 用户已有容器或独立实例，环境变量对接 | 不由业务镜像决定 |
| Ollama | 宿主机或独立服务，`JB_OLLAMA_BASE_URL` 对接 | 不进入业务镜像 |
