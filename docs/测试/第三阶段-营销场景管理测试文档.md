# 第三阶段：营销场景管理测试文档

## 1. 本阶段新增功能

新增“营销场景”业务配置层，用于把营销业务对象显式沉淀到平台中，而不是仅依赖智能体名称、知识库名称和权限配置来表达场景。

本阶段能力：

- 新增营销场景数据表 `marketing_scenario`。
- 新增工作空间级营销场景 API。
- 新增后台菜单 `/admin/marketing-scenario`。
- 支持营销场景创建、列表、搜索、编辑、删除。
- 支持关联当前工作空间内的智能体和知识库。
- 创建一条正式样例：`存量客户套餐升级营销场景`。

### 4.1 智能体语义跑偏修复与复测

问题现象：

- 在调试聊天页输入“套餐升级问题”时，智能体曾错误回答 MySQL/数据库升级步骤。

原因：

- 测试智能体的 `problem_optimization_prompt` 仍为默认通用问题补全提示词。
- 已发布版本 `ApplicationVersion` 的 `no_references_prompt` 仍为 `{question}`，无知识库召回或短问题召回不稳时，模型容易按通用语义自由发挥。
- 页面调试入口使用已发布版本，不能只修改草稿应用配置。

修复：

- 同步强化测试智能体草稿与所有已发布版本的：
  - 系统提示词；
  - 知识库提示词；
  - 无引用兜底提示词；
  - 问题补全提示词。
- 新增代码级窄范围兜底：当应用文本明显属于“电信/套餐/营销”场景，且无引用兜底仍为裸 `{question}` 时，自动使用通信套餐营销兜底提示，避免短问题跑到数据库、软件、系统升级领域。
- 修复开发环境静态资源：
  - 新增 `ui/public/locales/index.json`，解决 `/admin/locales/index.json` 404。
  - 将测试智能体图标改为 `/favicon.ico`，解决 `/admin/chat/favicon.ico` 404。

## 6. 当前边界

本阶段是低风险增量，不大规模改现有对话链路：

- 营销场景目前是配置层，不直接改变智能体回复逻辑。
- 关联智能体/知识库只校验当前工作空间归属。
- 菜单当前按登录可见处理，正式权限常量可在下一阶段补齐。

下一阶段建议：

- 增加营销活动/任务对象。
- 将营销场景与触发器或对话日志关联。
- 增加场景效果指标：触达量、对话量、意向量、转化率。
- 增加正式权限：`MARKETING_SCENARIO:READ/CREATE/EDIT/DELETE`。
