## 1. 交付结果

本阶段在既有通用指标事实表上完成八类主题趋势分析，没有新增重复的报表事实表：

- 八类主题全局概览：监控排障、安全隐患、成本效能、客户交付、网络运行、能力指标、维护优化、涉网涉数风险。
- 主题、指标、设备、网元、时段和起止时间筛选；主题筛选只影响当前趋势，八类总览继续显示相同维度/时段口径下的完整统计。
- 同图展示观测值、动态基线、关注阈值和紧急阈值；命中规则的数据点使用告警颜色标注。
- 观测详情关联指标定义、原始快照、采集批次、动态基线版本、规则配置版本、告警、派单和追加事件时间线。
- 八类主题样例每次生成 48 行观测数据，每类 6 个连续趋势点；异常行仍不进入统计和规则门禁。

## 2. 接口

| 接口 | 用途 |
| --- | --- |
| `GET /admin/api/workspace/{workspace_id}/metric-foundation/analytics` | 八类统计、筛选项、当前指标趋势和告警标注 |
| `GET /admin/api/workspace/{workspace_id}/metric-foundation/observation/{observation_id}` | 观测到批次、基线、告警、派单事件的事实下钻 |
| `POST /admin/api/workspace/{workspace_id}/metric-foundation/bootstrap` | 生成并保留八类主题 V1 验收样例 |

查询参数支持 `theme`、`definition_id`、`device`、`network_element`、`time_slot`、`start`、`end` 和 `limit`。起止时间倒置、跨工作空间指标和不存在的观测均由后端拒绝。

## 5. 已知边界

- 当前 V1 使用 ECharts 单指标折线，不提供多指标归一化叠加、环比/同比或预测区间，这些进入全量 V1 后的优化池。
- 主题卡的统计值可能属于不同单位，卡片用于同主题快速定位，不对不同主题数值直接做数学比较。
- 重复生成验收样例会追加新批次和历史事实，这是预期行为；验收数据按项目约定保留。
- 浏览器控制台存在两条项目既有的 Vue 生命周期 warning，但无 error，且与本页请求和交互无关。
