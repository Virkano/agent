# 增量学习 M07-04 验收文档

## 1. 验收范围

M07-04 对应建设方案 X04，在 M07-03 可解释精排上完成反馈闭环与增量策略粗粒度 V1：

- 每次精排自动记录候选曝光，并固化当时七项精排特征。
- 支持点击、转化、负反馈手工录入，事件标签分别为 `0.6`、`1.0`、`-1.0`；曝光标签为 `0`，只用于漏斗统计。
- 支持从营销触达与转化记录幂等同步反馈；意向映射为点击、拒绝/流失映射为负反馈、已转化映射为转化。
- 基于正负反馈的特征均值差调整已发布精排策略权重，生成独立新版本。
- 训练固化事件快照、权重变化和新旧成对排序准确率；仅在指标不退化时自动发布。
- 前端提供反馈操作、事件统计、业务同步、增量训练、版本变化和最近事件列表。

## 2. 增量基线

粗粒度 V1 使用确定性的反馈权重增量算法，不伪装成深度在线学习：

1. 去除曝光样本，要求至少一条正反馈和一条负反馈。
2. 对七项精排特征分别计算“加权正样本均值 - 负样本均值”。
3. 使用 `新权重 = max(0.001, 旧权重 × (1 + 学习率 × 特征信号))` 更新并归一化。
4. 对全部正负样本对计算旧策略和新策略的排序准确率。
5. 生成草稿版本；启用自动发布且新指标不低于旧指标时发布，旧发布版本自动归档。

该实现使训练输入、权重变化、离线门禁和发布结果均可复现、审计和回滚。

## 3. 数据模型与接口

- `RecommendationFeedbackEvent`：客户、活动、精排运行、事件类型、标签、来源、幂等键、特征快照和发生时间。
- `RecommendationIncrementalRun`：基线版本、生成版本、样本快照、学习率、正负样本数、权重变化、新旧指标和运行状态。
- `GET /marketing/recommendation/incremental-dashboard`
- `POST /marketing/recommendation/feedback`
- `POST /marketing/recommendation/incremental-sync`
- `POST /marketing/recommendation/incremental-train`

数据库迁移：`marketing.0030_recommendation_incremental_v1`，已应用到本地 PostgreSQL；非空事件幂等键按工作空间唯一。

## 7. V1 边界与下一步

- 本阶段调整的是可解释精排权重，不是持续常驻的流式神经网络训练。
- 触达意向/拒绝映射属于粗粒度代理标签，后续可在真实渠道联调后替换为严格点击与转化埋点。
- 当前使用全量有效反馈形成新版本；后续可增加时间窗口、样本衰减、训练/验证集和 A/B 灰度。
- 下一步 M07-05 / X05：建立 CTR、CVR、覆盖率、多样性、延迟和版本表现监控，完成推荐引擎 V1 收口。
