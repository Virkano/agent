# 场景模拟与人工闭环 M10-04 验收文档

## 1. 建设范围

P0-06 / M10-04 已完成，建设方案功能对比表 X21“场景模拟”形成可运行、可演示、可追溯的粗粒度 V1。

本步复用 M10-01～M10-03 的预演实例、申告批次、趋势批次和处置流程，增加：

- 版本化场景剧本和有序执行步骤编辑。
- 同一预演实例内的申告、趋势和处置流程多类数据注入。
- 创建时固化剧本与注入对象快照，避免后续源数据变化破坏审计。
- 启动、完成当前步骤、跳过、失败的场景执行状态机。
- 完成/失败后的自动场景总结、异常说明和执行统计。
- 人工工单创建、处理、解决、关闭、重开与追加式审计事件。

## 2. 数据模型与状态规则

新增 `RehearsalSceneScript`、`RehearsalSceneRun`、`RehearsalSceneStep`、`RehearsalSceneEvent`、`RehearsalWorkOrder` 和 `RehearsalWorkOrderEvent`。

默认剧本 `NETWORK-FAULT-SCENE-V1` 包含 5 步：校验注入数据、研判故障影响、执行协同处置、验证业务恢复、总结与转工单。

场景执行按“待执行 → 执行中 → 已完成/已失败/已取消”收口。运行中可完成或跳过当前步骤；任一步失败会终止场景并生成失败总结。人工工单按“待处理 → 处理中 → 已解决 → 已关闭”推进，已关闭工单可重开。所有状态变更都记录操作者、前后状态、说明和时间。

创建场景至少注入一类数据，且全部注入对象必须归属于所选预演实例。幂等请求编号避免重复创建执行和工单。

## 3. 管理接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-script` | 查询或新建场景剧本版本 |
| GET / POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-run` | 筛选或创建场景执行 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/instance/{instance_id}/scene-run` | 查询实例下的场景执行 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/scene-run/{run_id}` | 查看步骤、快照、总结、工单和审计 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-run/{run_id}/operate` | 启动、完成、跳过或失败收口 |
| GET / POST | `/admin/api/workspace/{workspace_id}/rehearsal/work-order` | 查询或新建人工工单 |
| GET / POST | `/admin/api/workspace/{workspace_id}/rehearsal/scene-run/{run_id}/work-order` | 查询或创建场景关联工单 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/work-order/{work_order_id}/operate` | 处理、解决、关闭或重开工单 |
