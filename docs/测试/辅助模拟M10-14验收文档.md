# 辅助模拟 M10-14 验收文档

## 1. 验收范围

对应建设方案 X31“辅助模拟”。本任务在统一预演实例上注入网络、故障和流量随机因子，固化可复现结果快照，并提供影响分析、统计对比、异常标注以及 PDF、Excel、JSON 报告下载。

粗粒度 V1 边界：随机因子用于演练和评估，不直接改变真实网络设备、生产流量或故障状态；报告反映模拟结果，不替代生产监控结论。

## 2. 已交付能力

- 内置网络抖动、随机丢包、故障传播延迟、故障扩散范围、随机流量峰值和流量波动频率六项因子。
- 每项因子支持正态或均匀分布、最小/最大值、触发概率和启停组合配置。
- 相同输入与随机种子生成相同业务结果和 SHA-256 校验和，时间戳不参与可复现性校验。
- 固化因子配置与采样结果、分钟级时序点、基线、关键时刻、影响分析、前后统计和异常窗口。
- 列表支持实例、状态和关键字筛选；详情展示趋势、统计、影响和异常点。
- X26 统一模拟记录新增 `AUXILIARY_SIMULATION` 类型，并在实例汇总和审计事件中同步体现。
- 报告支持 `summary`、`full` 两个层级，以及 PDF、Excel、JSON 三种格式；完整版包含分钟级原始数据。
- 管理端新增“辅助模拟”控制台、因子目录、结果趋势、创建抽屉、详情抽屉和快捷下载。

## 3. 数据模型与迁移

迁移：`apps/rehearsal/migrations/0013_alter_rehearsalinstanceevent_event_type_and_more.py`。

- `RehearsalAuxiliarySimulation`：保存工作空间、实例、请求幂等键、批次编号、种子、时长、状态、因子快照、结果快照、校验和及执行时间。
- `RehearsalInstanceEvent.AUXILIARY_SIMULATED`：记录辅助模拟已完成的追加式实例事件。

## 4. 接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/auxiliary-simulation` | 筛选、分页和汇总辅助模拟 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/instance/{instance_id}/auxiliary-simulation` | 按种子和因子组合执行模拟 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/auxiliary-simulation/{simulation_id}` | 查看结果快照、趋势、影响、统计和异常 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/auxiliary-simulation/{simulation_id}/export` | 使用 `export_format` 与 `report_level` 下载报告 |

下载参数必须使用 `export_format=pdf|xlsx|json`，不能使用 DRF 保留的 `format` 查询参数。

## 8. 手工测试方法

1. 打开“故障与场景预演”，定位“辅助模拟”区域。
2. 点击“创建辅助模拟”，选择未终止实例，填写种子和时长。
3. 调整六项因子的启停、分布、范围与触发概率；执行后查看趋势和异常数。
4. 使用相同种子和相同配置再次执行，核对业务结果与校验和一致。
5. 打开详情，核对因子采样、影响说明、统计变化和异常窗口。
6. 分别下载精简版/完整版 PDF、Excel、JSON，确认完整版包含分钟级原始数据。
