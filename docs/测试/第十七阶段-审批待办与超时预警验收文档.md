# 第十七阶段：审批待办与超时预警验收文档

## 目标

让营销主管无需逐个进入任务查找待审批批次，并明确识别超过审批时限的事项，缩短批次从创建到可执行的等待时间。

## 规则说明

- 每个营销任务可在创建或编辑时设置“审批时限（小时）”，范围为 1～168 小时；未配置时默认 24 小时。
- 新建批次和被驳回后重新提交的批次，都会按当前任务的审批时限生成新的审批截止时间。
- 仅“待审批”且已超过截止时间的批次会标记为“已超时”。已通过、已驳回、已执行的批次不计入超时待办。
- 待办中的审批权限仍沿用第十六阶段规则：系统管理员或工作空间管理员可审批，但创建人不能审批自己创建的批次。

## 页面操作

1. 进入“营销任务”，创建或编辑任务，在“审批时限（小时）”填写时限，例如 24。
2. 为任务创建触达批次。批次表会显示“审批截止 / 超时”列。
3. 在营销任务页面右上角点击“审批待办”。
4. 抽屉中查看待审批总数、超时数量，以及按截止时间排序的批次列表。
5. 对自己有权限审批的记录点击“审批”，可直接完成通过或驳回；审批完成后待办和任务内批次列表会自动刷新。
6. 进入任务详情的看板，检查“审批超时 / 平均耗时”指标；审批通过后的耗时会纳入平均值。

## 验收结果

- 数据库迁移 `marketing.0008_marketingtouchbatch_approval_due_at` 已应用。
- 使用临时超时批次验证：批次超时标记正确；审批待办接口的超时数和任务看板的超时数一致。
- 真实路由 `GET /admin/api/workspace/{workspace_id}/marketing/approval-queue` 返回 HTTP 200。
- Django 系统检查、迁移一致性检查、后端 Ruff、前端 Vue 类型检查与 ESLint 均通过。
- 自动化验收创建的临时批次和审批记录已清理，原任务配置已恢复。

## 边界说明

本阶段的“预警”是页面待办、超时标识和看板统计，避免遗漏审批事项；不自动发送站内信、短信或企业消息，也不自动替代人工审批。若后续需要逐级催办或超时升级，可在现有截止时间和审批留痕基础上接入通知任务。
