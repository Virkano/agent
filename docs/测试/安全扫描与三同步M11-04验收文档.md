## 可重复执行

从仓库根目录执行：

```bash
./.venv/bin/python scripts/m11_security_scan.py --image jb-agent:slim-local --report-only
./.venv/bin/python -m unittest scripts.test_m11_security_scan
./.venv/bin/ruff check scripts/m11_security_scan.py scripts/test_m11_security_scan.py
```

`--report-only` 用于保存基线报告；不带此参数时，只要有发现、错误或三同步未完成就返回非零，适合后续接入门禁。扫描只读，不执行依赖自动修复、镜像拉取或登录。报告在 `output/m11-04/`：`summary.json` 记录输入文件 SHA-256、扫描状态与检查表快照；原始 Python/前端报告仅供本地排查，不应直接公开。脚本对报告使用仅当前用户可读权限。
