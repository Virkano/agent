# M11-01 部署安全基线验收

日期：2026-09-21。范围：M11 的首个最小增量，解决容器默认口令和生产设置静默降级风险。

## 交付

- Dockerfile 和通用配置不再提供 PostgreSQL、Redis 口令默认值；容器运行阶段默认 `JB_DEPLOYMENT_MODE=production`。这不是全仓库秘密扫描结论。
- `.dockerignore` 排除仓库根目录的 `.env*`、本地浏览器会话、学习记录和运行数据，避免 `COPY .` 将本地配置与验收产物带进镜像；预检会检查根目录环境文件忽略规则。
- 生产启动前执行 `scripts/check-deployment-security.py --production`。必须显式提供 `JB_SECRET_KEY`、`JB_DB_PASSWORD`、`JB_REDIS_PASSWORD`、`JB_DEFAULT_PASSWORD`、`JB_ALLOWED_HOSTS`，拒绝开发默认值、通配域名和开启 DEBUG。失败信息仅列配置项名称或规则，不输出密钥内容。
- Web 与本地模型设置共用生产门禁；生产启用安全会话/CSRF Cookie、HTTPS 重定向、短期 HSTS 和内容类型保护。本地开发模式保留原有配置与启动方式。
- 独立预检可在仓库根目录运行：`./.venv/bin/python scripts/check-deployment-security.py` 检查镜像静态安全；在部署环境使用 `--production` 检查完整生产配置。反向代理必须终止 TLS，并正确传递 `X-Forwarded-Proto: https`，否则 HTTPS 重定向不能正常结束。
- 对已初始化的数据库，设置新的 `JB_DEFAULT_PASSWORD` 不会自动修改既有管理员账户密码；上线前须另行轮换现有账户并验证权限。

- Django `check`、目标文件 Ruff、独立本地预检通过。
