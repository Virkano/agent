# 第十二阶段：客户分层、触达批次与待办队列验收文档

## 1. 本阶段交付

在“营销任务 → 客户名单”中新增两项运营能力：

- **触达批次**：按客户状态、套餐关键词、省份、近月流量和通话量筛选客户，生成不可变的入选/排除快照。
- **待跟进队列**：按处理优先级集中展示客户，顺序为“转人工 → 有意向 → 已咨询 → 待触达 → 已触达”；无意向客户默认不进入队列。

本阶段不会自动发送短信、外呼或向客户发起新对话。批次只提供可复核的筛选依据，实际沟通仍由坐席在已有客户对话中完成。

## 2. 使用步骤

1. 进入管理端的“营销任务”，打开目标任务的“客户”入口。
2. 点击“触达批次”，再点击“生成批次”。
3. 填写批次名称，并按需要配置：
   - 客户状态（必选，默认“待触达”）；
   - 套餐关键词，例如 `199`；
   - 省份，例如 `广东`；
   - 最低流量/通话门槛；
   - 冷却期，默认 7 天。
4. 点击“生成”。列表会显示入选人数、排除人数、筛选条件和生成时间。
5. 点击“待办队列”，按优先级查看应优先处理的客户；回到客户名单后可点击“测试”进入该客户的既有对话，或点击“跟进”记录人工结论。

## 3. 规则说明

- 批次一经生成，入选和排除客户均以快照保存，后续客户资料变化不会篡改历史批次。
- 排除原因会被保存，例如：状态不匹配、套餐/省份不匹配、流量/通话未达门槛、仍处于冷却期。
- 客户进入批次后会记录最近批次信息；冷却期内再次筛选时会自动排除，避免重复触达。
- 每个工作空间的任务、客户和批次都按工作空间隔离，其他工作空间可独立使用同一功能。

## 5. 建议的人工复测

1. 生成一个“待触达 + 199 套餐 + 广东”的批次，检查列表的入选和排除人数是否符合名单。
2. 用相同条件且冷却期为 7 天再次生成，确认上一次入选客户的排除原因显示为“最近 7 天已进入触达批次”。
3. 打开“待办队列”，确认“转人工”和“有意向”客户排在前面，无意向客户不出现。
4. 进入任一客户对话并记录“跟进”，再刷新待办队列，确认客户状态与排序随之更新。
