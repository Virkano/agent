## 3. 真实浏览器验收

在 `http://127.0.0.1:3000/admin/analysis-report` 完成以下操作：

1. 生成线性归因报告，报告库、指标、经营解读和“线性归因分布”正常显示。
2. 下载 HTML、PDF、Word，浏览器均收到正确文件名；文件类型分别识别为 HTML、PDF 1.4 和 Microsoft OOXML。
3. 新建“每天 09:00”的线性归因订阅，卡片显示下次执行时间为次日 09:00。
4. 点击“立即执行”，新报告进入报告库，未读通知数增加。
5. 打开右上角全局通知，报告通知标记为“报告完成”，包含标题、摘要和正确本地时间；页面未新增独立通知入口。
6. 在嵌套布局中滚动到报告底部，“线性归因分布”和“渠道覆盖”均可见。
7. 浏览器控制台 0 个错误；8 个警告为仓库既有国际化提示。
