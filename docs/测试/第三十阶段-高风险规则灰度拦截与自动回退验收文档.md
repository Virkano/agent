# 第三十阶段：高风险规则灰度拦截与自动回退验收文档

## 1. 本阶段目标

把上一阶段的“规则效果分析”升级为可控的发送前灰度拦截，但不改变默认行为：

- 工作空间默认仍为影子检测。
- 只有通过人工样本和准确率门槛的高风险规则可以启用。
- 只拦截管理员明确勾选的规则，其余规则继续记录。
- 检测超时或异常时优先保证对话可用，原回答继续发送并记录旁路原因。
- 支持管理员一键回退；规则复核结果变差时系统自动降级。

## 2. 灰度准入条件

规则必须同时满足以下条件：

1. 规则风险级别为高风险。
2. 已人工复核样本不少于 20 条。
3. 问题确认率不低于 90%。
4. 误报率不高于 5%。

不满足条件的规则不会出现在“本工作空间拦截规则”中，后端接口也会再次校验，不能通过绕过页面强行启用。

## 3. 管理员操作流程

1. 登录管理端并切换到目标工作空间。
2. 打开“对话质检”。
3. 在“规则效果分析”中确认“可进入灰度候选”数量大于 0。
4. 在“发送前质量策略”中选择“灰度拦截”。
5. 在“本工作空间拦截规则”中勾选需要启用的已准入规则。
6. 点击“保存策略”。
7. 完成营销对话后，在“发送前质量检测记录”查看处理动作、原始回答、最终回答、命中规则和检测耗时。

需要立即停用时，点击“一键回退影子模式”。回退后只记录新风险，不再新增自动拦截。

## 4. 发送前处理逻辑

当营销对话所在工作空间为灰度拦截模式时：

1. 服务端先缓冲模型完整回答，不提前把风险文本流式发送给客户。
2. 执行确定性质量检测。
3. 若命中已勾选规则，向客户发送安全兜底回答。
4. 若只命中未勾选规则，原回答正常发送并保留检测记录。
5. 若检测超过 300ms 或发生异常，原回答正常发送，并记录为“异常旁路”。
6. 对话记录保存客户实际收到的最终回答；发送前记录同时保存模型原始回答和最终回答。

灰度拦截的客户安全答复为：

> 这个问题涉及具体资费或办理规则，我暂时无法确认准确结果。为避免给您错误信息，建议由当地人工客服进一步核实后再办理。

## 5. 自动回退

灰度启用后，人工复核仍会持续影响规则效果：

- 某条已启用规则不再满足准入门槛时，系统自动将其从拦截白名单移除。
- 若白名单中已没有可用规则，工作空间自动回退到影子检测。
- 策略更新人显示为“系统自动回退”，便于审计。

## 6. 接口说明

- 查询策略：`GET /admin/api/workspace/{workspace_id}/marketing/quality-policy`
- 更新策略：`PUT /admin/api/workspace/{workspace_id}/marketing/quality-policy`
- 检测记录：`GET /admin/api/workspace/{workspace_id}/marketing/preflight-log`
- 规则效果：`GET /admin/api/workspace/{workspace_id}/marketing/quality-rule-effect`

启用示例：

```json
{
  "mode": "INTERCEPT",
  "intercept_rule_types": ["INTERNAL_EXPOSURE"]
}
```

一键回退示例：

```json
{
  "mode": "SHADOW",
  "intercept_rule_types": []
}
```
