# 营销告警系统最终收口验收

## 收口结论

营销告警能力已按单一全局入口完成闭环。用户统一从页面右上角告警铃铛接收和进入告警，不再建设页面级重复通知入口。

本次最终收口覆盖规则配置、触发去重、处理协作、SLA 升级、复盘降噪、规则效果评估、阈值模拟、变更留痕和历史回滚。告警相关功能不再拆分后续开发阶段。

## 已完成能力

- 全局告警铃铛：未读数、告警列表、全部已读、单条跳转。
- 告警规则：启停、级别、触发阈值、首次响应 SLA、处理完成 SLA、升级接收人。
- 规则效果：按 7/30/90 天统计信号事件、刷新/重开、重复率、关闭数、误报率和平均处理时长。
- 阈值治理：根据重复率、误报率和触发样本生成推荐阈值，并展示候选阈值的预计触发数和减少比例。
- 安全变更：每次规则修改前自动保存完整快照、操作人和原因；支持选择历史版本回滚，回滚前同样保存当前配置。
- 告警生命周期：自动创建、去重刷新、认领、开始处理、关闭、来源恢复后重新打开。
- SLA 管理：首次响应和处理完成时限、超时升级、负责人轮次及达标率统计。
- 协作处理：指派、转派、评论、关注人、附件和完整操作时间线。
- 结构化关闭：根因分类、处置方式、影响范围和处理结论。
- 复盘降噪：根因/处置分布、复发告警、历史经验复用、高噪声识别和合并建议。

## 新增接口

- `GET /workspace/{workspace_id}/marketing/alert-rule-effect`：规则效果、阈值模拟、推荐值和最近十条变更历史。
- `PUT /workspace/{workspace_id}/marketing/alert-rule/{rule_id}`：保存规则并记录变更前快照和变更原因。
- `POST /workspace/{workspace_id}/marketing/alert-rule/{rule_id}/rollback`：回滚到指定历史快照，并保存回滚前配置。

## 模拟口径说明

阈值模拟只使用当前规则已经捕获的触发样本。低于现有阈值的原始指标不会进入告警动作历史，因此预计触发数用于辅助判断，不等同于离线全量回放。页面已明确展示该限制，并为推荐结果标注低、中、高可信度。
