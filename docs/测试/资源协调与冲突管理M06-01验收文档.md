# 资源协调与冲突管理 M06-01 验收文档

## 1. 验收结论

M06-01 / X16 粗粒度 V1 已完成。系统已具备工作空间级资源池、并发配额、优先级等待队列、互斥资源、请求/幂等去重、持久化租约、显式过期回收和追加式事件台账，并提供“资源协调中心”管理页面。

## 2. 交付范围

- 资源池：智能体、模型、工具、执行器四类资源，支持总配额、单任务上限、租约超时和启停状态。
- 调度任务：支持 webhook、定时、用户和系统来源，优先级 1～100、申请配额、来源引用、请求编号和幂等键。
- 冲突门禁：事务内校验可用配额与互斥键；无法分配的任务进入持久化等待队列并记录原因。
- 租约状态：分配后保存占用单位、互斥键、起止时间；完成、失败、取消和过期回收都会释放资源并继续调度等待任务。
- 事实链：提交、排队、分配、成功、失败、取消和租约过期均形成不可覆盖事件。
- 管理页面：资源态势指标、配额地图、运行/等待棋盘、任务台账、新建资源池、提交任务和任务详情抽屉。
