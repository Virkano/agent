# 第二十三阶段：灰度效果与放量建议验收文档

## 操作

1. 在“营销活动库”选择活动，点击“效果”。
2. 系统只统计会话归因明确命中该活动的客户，展示命中会话、客户、意向率、转人工率和办理数。
3. 无命中数据时建议“继续灰度”；意向率达标或已有办理时建议“扩大批次”；转人工率达到 30% 或明确无意向率达到 60% 时建议“暂停活动”。
4. 在营销任务填写“首批灰度人数”，首次触达批次会自动截取该人数。放量时新建下一触达批次，不能修改历史批次或历史会话快照。

## 自测

- 后端 `ruff` 与 Django `manage.py check` 通过。
- 前端 `vue-tsc --noEmit` 通过。
- 活动效果接口受登录鉴权保护；后端重启加载新路由。
