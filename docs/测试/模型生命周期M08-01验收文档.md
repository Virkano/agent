# 模型生命周期 M08-01 验收文档

## 1. 验收结论

M08-01 已完成粗粒度 V1：支持工作空间内的模型实验、模型版本注册、准入评估、发布切换、历史版本回滚和发布审计，并提供可操作的管理端页面。

本阶段覆盖 X32 的生命周期基础，以及 X33 的手动评估和发布门禁基础。外部 MLflow、自动训练/部署/重训、非结构化 ETL 版本发布和全维监控不在本阶段完成范围，进入 M08-02 及后续任务。

## 2. 已实现范围

- 实验：创建、查询、状态流转、工作空间隔离和安全删除。
- 版本：基于已完成实验注册，同一注册模型名称自动递增版本号。
- 评估：支持数值指标的最小值、最大值准入阈值，保存每次评估记录。
- 发布：只有存在通过评估记录的版本才可发布；发布新版本会归档原线上版本。
- 回滚：历史通过版本可重新发布，保留来源版本、目标版本、原因和操作人。
- 扩展：提供本地生命周期跟踪适配器和外部跟踪器接入边界。
- 页面：模型管理页入口、概览卡片、实验管理、版本与发布、发布审计三个页签。

## 3. 数据库与接口

迁移：`models_provider.0003_model_lifecycle_v1` 已应用到本地 PostgreSQL。

新增核心表：

- `model_lifecycle_experiment`
- `model_lifecycle_version`
- `model_lifecycle_evaluation`
- `model_lifecycle_release_record`

接口前缀：`/admin/api/workspace/{workspace_id}/model-lifecycle/`

已覆盖概览、实验 CRUD、版本 CRUD、评估、发布、回滚和发布记录查询。
