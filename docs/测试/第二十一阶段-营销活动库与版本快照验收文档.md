# 第二十一阶段：营销活动库与版本快照验收文档

## 本阶段交付

- 新增工作空间级“营销活动库”，独立维护活动编码、状态、版本、客户可见权益、费用/合约边界、适用套餐、省份、用量门槛和生效期。
- 营销任务可从活动库多选“已上线”活动；保存任务时，系统将所选活动及版本复制为任务快照。
- 新建客户对话优先使用任务活动快照；未选择活动的既有任务仍使用原场景中的推荐策略，不影响已运行配置。
- 后续编辑、暂停或归档活动不会回写既有任务、历史会话或历史推荐归因。活动自身版本会递增，便于审计。

## 操作步骤

1. 登录后台，进入左侧菜单“营销活动库”。
2. 点击“新建活动”，填写活动名称、唯一活动编码和“客户可见权益”。费用说明与合约说明必须是已确认的边界，不要填写未经核实的金额或承诺。
3. 需要立即被任务使用时，将状态设为“上线”；草稿和暂停活动不能被任务选择。
4. 按实际政策填写适用套餐关键词、省份、流量/通话门槛及生效日期，保存后会生成 `v1`。
5. 进入“营销任务”→“创建任务”或“编辑”，在“营销活动库”多选已上线活动并保存。
6. 进入该任务的“客户”页，选择命中条件的客户并打开“测试”。询问套餐升级或流量不足时，回复应只引用该任务快照中的活动权益、费用和合约边界。

## 验收场景

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 活动创建 | 保存上线活动 | 列表显示 `v1`，可被任务下拉列表选择 |
| 活动选择 | 在任务中选择一个上线活动后保存 | 任务详情显示已关联活动；任务配置保存活动快照 |
| 客户命中 | 客户套餐、省份、用量均满足活动条件 | 新对话的推荐归因命中该活动，回复仅包含配置的客户可见权益 |
| 后续变更 | 将原活动改为暂停、修改权益后保存 | 活动变为 `v2`；已创建任务仍使用 `v1` 的原权益 |
| 归档 | 归档活动 | 新任务不可再选择；既有任务与历史对话保持可追溯 |
| 兼容性 | 任务不选活动 | 沿用营销场景的既有推荐策略，不影响老任务 |

## 约束与处理方式

- 活动库只存可对客户展示的确定性政策边界，不能将“建议坐席话术”、内部操作说明或未经确认的资费写入客户权益。
- 大范围策略调整采用“新建/更新活动版本 → 新建任务选择新版活动 → 小批客户验证 → 再扩大”的方式，不直接修改运行中任务的快照。
- 需要改变已运行任务的推荐内容时，应在任务编辑页重新选择活动并保存；该操作只影响之后创建的会话，历史会话仍以其自身归因记录为准。
