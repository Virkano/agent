# 第二十四阶段：放量建议执行闭环验收文档

## 操作流程

1. 在“营销活动库”打开某活动的“效果”。
2. 建议为“扩大批次”时，选择关联该活动快照的营销任务，点击“创建放量批次”。
3. 系统按建议人数和最近批次筛选条件创建**新的**触达批次，状态为“待审批”；工作空间主管在营销任务的审批待办中通过后才可执行。
4. 建议为“暂停活动”时，点击“暂停活动”。活动将不能被新任务选择，已创建任务、批次和会话继续保留原快照与归因。

## 强制校验

- 放量前验证活动必须是“审批已通过 + 已上线”。
- 只能选择确实关联该活动快照的营销任务。
- 放量不会复用或修改旧批次，始终创建新批次并走既有审批流程。
