# API 编排与晓搭适配底座 M05-01 验收文档

## 1. 交付结果

- 新增工作空间级 API 资产，保存接口标识、名称、说明、图标、鉴权方式、凭证引用和 IP 白名单。
- 契约版本固化环境、请求方法、路径、输入/输出 Schema、字段映射和 Mock 返回；新建版本不覆盖历史。
- 发布新版本时归档旧发布版；回滚不改写历史，而是基于目标快照创建并发布新版本。
- 晓搭 Mock 调用覆盖调用成功、鉴权失败、输入 Schema 失败和返回 Schema 失败四种结果。
- 每次调用保存追加式审计事实；请求快照只含协议、工具标识、版本和业务参数，不保存真实凭证。
- 新增“API 编排与晓搭”菜单和操作台，支持登记、新版本、发布、回滚、三类一键调用和审计详情。

## 2. 主要接口

| 接口 | 用途 |
| --- | --- |
| `GET /admin/api/workspace/{workspace_id}/api-orchestration/dashboard` | 资产、版本和调用概览 |
| `POST /admin/api/workspace/{workspace_id}/api-orchestration/asset` | 登记 API 资产并生成 V1 草稿 |
| `PUT /admin/api/workspace/{workspace_id}/api-orchestration/asset/{asset_id}` | 基于当前配置生成新草稿版本 |
| `POST .../version/{version_id}/publish` | 发布指定版本并归档旧发布版 |
| `POST .../version/{version_id}/rollback` | 基于历史快照创建并发布回滚版本 |
| `POST .../mock-invoke` | 执行晓搭协议 Mock 调用并追加审计 |
| `POST /admin/api/workspace/{workspace_id}/api-orchestration/bootstrap` | 生成可保留的 V1 验收样例 |

## 5. 已知边界与下一步

- 当前是晓搭协议 Mock，尚未连接真实晓搭网关。
- API Key、JWT、OAuth2、签名和 IP 白名单已有配置入口；当前 Mock 鉴权只接收内部已验证上下文，不是生产凭证校验器。
- 当前 Schema 覆盖 JSON object 的必填字段、基本类型和额外字段限制；OpenAPI 导入、参数来源/依赖、契约版本对比进入 M05-02。
- 启用/停用、测试/灰度/生产转移门禁、超时/重试/熔断和真实外部联调进入 M05 后续任务。
