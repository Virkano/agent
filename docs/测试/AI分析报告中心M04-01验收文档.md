# AI 分析报告中心 M04-01 验收文档

## 1. 验收范围

本阶段完成“数据计算 → 模板生成 → 报告库”最小闭环：

- 接入营销任务、客户、触达批次、触达执行和确认转化数据。
- 计算曝光、触达、触达率、转化、转化率、归因收入、营销投入、变动成本、边际贡献和 ROI。
- 支持工作空间级报告模板、模板版本、标题变量和智能解读提示词。
- 无 LLM 时生成规则分析；选择可用 LLM 时生成模型解读。
- 保存报告指标快照、HTML 正文、生成运行记录和失败原因，失败报告可重试。
- 提供报告库、状态/关键词筛选、详情预览、模板管理和生成表单。
- 后端与前端都使用当前工作空间角色和数据范围隔离。

M04 的最终点击/线性归因、基础图表、定时订阅、全局铃铛通知、邮件适配以及 PDF/Word 下载安排在 M04-02。

## 4. 手工复验方法

1. 展开头部“运营治理”，进入“AI 分析报告”。
2. 点击“生成报告”，先关闭“模型智能解读”验证基础闭环。
3. 选择营销任务可验证真实曝光、触达和转化数据；不选则汇总工作空间全部任务。
4. 输入经营收入与成本，提交后核对报告库、指标表和经营解读。
5. 需要验证本地模型时，先确认 Ollama 和目标 LLM 在线，再打开智能解读并选择模型。
6. 模型不可用时报告应保留为“生成失败”，恢复模型后点击“重试生成”。
