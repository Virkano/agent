# 第二十八阶段：发送前影子质检与依赖降级验收文档

## 1. 本阶段目标

把营销回答质量检查接入客户发送边界，但先以“影子检测”方式运行：记录模型原始回答、最终发送回答、规则结论和处理动作，不因新质检规则改变客户收到的内容。现有资费安全规则继续生效。

本阶段同时修复真实浏览器测试发现的依赖故障：本地向量/Embedding 服务不可用时，营销对话不再向客户展示 `Expecting value` 等技术错误，也不再把该故障变成对话接口 500。

## 2. 交付内容

1. 工作空间级发送前质量策略：`关闭`、`影子检测`。
2. 默认策略为影子检测；未创建显式配置的工作空间也可直接使用。
3. 每条营销回答保存模型原始回答与最终发送回答。
4. 保存质检状态、分数、风险类型、原因、证据、规则版本和检测耗时。
5. 记录处理动作：`仅观察` 或 `安全规则已改写`。
6. 对话质检页新增策略配置和发送前影子检测记录，可展开比对原始/最终文本。
7. 营销知识检索失败时降级为无引用生成；生成链路仍失败时返回客户可理解的安全兜底文案。
8. 非营销对话保留原有异常行为，避免扩大本次改动范围。

## 3. 操作与测试步骤

### 3.1 开启影子检测

1. 登录管理端并选择目标工作空间。
2. 打开“对话质检”。
3. 在“发送前质量策略”中选择“影子检测”。
4. 点击“保存策略”。

预期结果：提示“影子检测已开启，不会拦截客户回答”。策略是工作空间级配置，不影响其他工作空间的独立设置。

### 3.2 发起真实营销对话

1. 打开“营销任务”。
2. 进入任务的客户名单。
3. 找到“张女士”，点击“测试”。
4. 新建对话并输入：`我流量经常不够，升级会不会有额外费用？`

本轮真实验收收到的最终回答：

> 套餐升级是否会增加费用，要以您当地实际可办理的方案为准。办理前会先向您确认月费变化、优惠期限和合约期，确认清楚后再由您决定是否办理。

预期结果：

- 对话接口成功，不出现 404 或 500。
- 回答不包含数据库、软件升级、异常堆栈、`Expecting value` 或内部“建议坐席话术”。
- 页面显示营销知识库引用。
- 不编造具体优惠价格或承诺一定免费。

### 3.3 检查影子记录

1. 返回“对话质检”。
2. 在“发送前影子检测记录”点击“刷新记录”。
3. 展开最新一行。

预期结果：可以看到模型原始回答、最终发送回答及检测结论。本轮记录为：

- 检测结论：正常，100 分。
- 处理动作：安全规则已改写。
- 检测耗时：57 ms。
- 模型原始回答包含“可能会增加额外费用”的不确定表达。
- 最终发送回答明确要求以当地可办理方案为准，并在办理前确认月费、优惠期限和合约期。

“安全规则已改写”来自项目原有资费安全规则；新增的影子检测仅记录，不再次改写或拦截。

### 3.4 关闭影子检测

1. 将策略改为“关闭”并保存。
2. 再完成一条营销对话。

预期结果：客户对话仍正常，现有资费安全规则仍生效，但不新增发送前影子检测记录。测试完成后建议恢复为“影子检测”。

## 4. 依赖异常处理

当营销知识库的 Embedding 或向量查询不可用时：

1. 服务端记录完整异常，便于运维定位。
2. 当前知识检索步骤返回空引用并继续生成。
3. 对话详情标记检索降级，便于后续排查。
4. 若生成链路仍失败，客户只收到与套餐办理有关的安全提示，不收到 Python/JSON/数据库错误文本。
5. 对话接口保持可用，不因该依赖异常返回 500。

本地联调时应同时启动前端、后端和本地模型/Embedding 服务；降级能力是故障兜底，不是长期替代正常知识检索。

## 5. 后端接口

- 查询策略：`GET /admin/api/workspace/{workspace_id}/marketing/quality-policy`
- 更新策略：`PUT /admin/api/workspace/{workspace_id}/marketing/quality-policy`
- 影子记录：`GET /admin/api/workspace/{workspace_id}/marketing/preflight-log/{current_page}/{page_size}`

更新请求示例：

```json
{
  "mode": "SHADOW"
}
```

影子记录支持 `task_id`、`status`、`action`、`keyword` 查询参数。

## 7. 当前安全边界

本阶段没有开放“高风险自动拦截”。这是有意保留的安全边界：未经误报率验证就拦截，会大规模改变现有对话主流程并可能误伤正常回答。

下一阶段应先按规则统计影子检测与人工复核的一致率、误报率和漏报样本，再只对确认率足够高的高风险规则开放工作空间级灰度拦截。拦截设计必须带超时、失败旁路、原始/最终文本留痕和一键关闭能力。
