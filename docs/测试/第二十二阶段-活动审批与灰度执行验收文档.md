# 第二十二阶段：活动审批与灰度执行验收文档

## 流程

1. 运营人员新建或编辑活动：活动保存为草稿，不能直接上线。
2. 创建人点击“提交”，活动进入“待审批”。
3. 非创建人的工作空间主管点击“通过”，活动才变为“已上线”；驳回必须填写原因。
4. 编辑已通过活动会自动暂停并回到草稿，必须重新提交，避免静默修改线上策略。
5. 营销任务填写“首批灰度人数”。首次生成触达批次时，系统最多入选该人数，其余客户在快照中标记为灰度上限排除。
