# 第三十五阶段：营销告警工单与负责人绩效验收文档

## 1. 本阶段目标

在已有“告警生成—站内通知—认领—处理—关闭—SLA 升级”链路上增加负责人工作台，让运营主管能够查看未认领工单、负责人待办、平均响应与处理时长，并按负责人下钻到具体告警。

本阶段复用 `marketing_alert` 的负责人、状态和 SLA 时间字段，不新建重复工单表，不修改营销对话、质检或触达执行主链路，也不增加数据库迁移。

## 2. 用户能看到的变化

- 告警处理台新增“负责人”筛选，支持选择具体负责人或“未认领”。
- 新增“仅看未关闭”筛选，可快速查看当前待办。
- 运营监控页新增“负责人告警工单”区域，展示当前周期的工单总数、处理中、未认领、平均首次响应、平均处理时长和综合 SLA 达标率。
- 负责人明细展示工单数、未关闭数、当前 SLA 超时数、已关闭数、平均响应/处理时长，以及响应、处理和综合达标率。
- 点击“查看待办”会自动设置负责人和未关闭筛选，并滚动到告警处理台。

## 3. 统计口径

统计周期支持近 7、30、90 天，以告警本轮 `sla_started_at` 为准；告警重新打开后从新一轮 SLA 开始时间计入。

| 指标 | 口径 |
| --- | --- |
| 工单总数 | 统计周期内开始本轮 SLA 的告警数 |
| 未关闭 | 当前状态不是“已关闭”的告警数 |
| 未认领 | 当前未关闭且负责人为空的告警数 |
| SLA 超时 | 当前来源仍异常，且首次响应或处理完成已超过截止时间的未关闭告警数 |
| 平均首次响应 | `first_responded_at - sla_started_at`，只统计已响应告警 |
| 平均处理时长 | `closed_at - sla_started_at`，只统计已关闭告警 |
| 响应达标率 | 按时响应数 ÷（已响应数 + 已到响应截止但仍未响应数） |
| 处理达标率 | 按时关闭数 ÷（已关闭数 + 已到处理截止但仍未关闭数） |
| 综合 SLA 达标率 | 按时完成的响应与处理里程碑数 ÷ 已完成或已超时的里程碑数 |

尚未到截止时间且尚未完成的里程碑不提前计为成功或失败；已经超时但未完成的里程碑计入分母并判为未达标，避免达标率虚高。

## 4. 接口

新增负责人绩效接口：

```http
GET /admin/api/workspace/{workspace_id}/marketing/alert-performance?days=7
```

响应包含：

- `range`：统计开始、结束时间和周期。
- `summary`：工作空间汇总指标。
- `workload`：按当前负责人聚合的指标；负责人为空时返回“未认领”。

告警分页接口新增查询参数：

```text
assignee_id={用户ID}
unassigned=true
active_only=true
```

`assignee_id` 与 `unassigned=true` 不能同时使用。所有查询继续按 `workspace_id` 隔离。

## 5. 手工验收步骤

### 5.1 查看负责人工作量

1. 登录管理端，进入“营销运营监控”。
2. 切换近 7、30、90 天，确认负责人统计周期同步变化。
3. 确认未认领、未关闭和 SLA 超时数量与告警处理台一致。
4. 对一条告警执行“认领”，确认该告警从“未认领”移动到当前负责人名下。
5. 关闭一条告警，确认负责人未关闭数减少、已关闭数增加，平均处理时长更新。

### 5.2 下钻负责人待办

1. 在负责人明细中找到未关闭数大于 0 的负责人。
2. 点击“查看待办”。
3. 确认页面滚动到告警处理台，并自动选中该负责人和“仅看未关闭”。
4. 确认列表不包含其他负责人或已关闭告警。
5. 对“未认领”行执行同样操作，确认只显示尚未认领的告警。

### 5.3 核对 SLA 统计

1. 准备一条按时响应、按时关闭的告警，确认两个里程碑均计为达标。
2. 准备一条响应超时但尚未响应的告警，确认响应达标率分母增加、达标数不增加。
3. 准备一条处理超时但尚未关闭的告警，确认处理达标率分母增加、达标数不增加。
4. 准备一条仍在时限内的未完成告警，确认它不提前影响达标率。

## 8. 当前边界与下一步

本阶段按告警当前负责人归集历史耗时；告警重新打开后会清空负责人并开始新一轮 SLA，但仍复用同一条告警记录。若后续需要跨轮次、跨负责人的绩效归属，应新增独立的告警处理轮次模型，不能仅依赖当前负责人字段。

建议下一阶段优先补“告警转派与协作记录”：支持主管指派、负责人转派、转派原因、处理评论和附件，并明确转派前后 SLA 与绩效归属规则；外部通知渠道继续作为可插拔适配器单独建设。
