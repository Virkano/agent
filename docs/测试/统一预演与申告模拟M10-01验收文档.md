# 统一预演与申告模拟 M10-01 验收文档

## 1. 验收结论

P0-06 / M10-01 已完成，建设方案功能对比表 X18“申告模拟”形成可运行、可演示、可追溯的粗粒度 V1。

本次不是只增加一个模拟数据页面，而是先建立 X18～X31 可复用的统一预演基础：场景、模板、实例、数据批次、实例状态机和追加式事件轨迹。X18 在此底座上完成公众客户数据、公众客户申告、政企客户数据模板、政企客户申告、时序申告以及人工导入模拟申告数据六项范围。

## 2. 交付范围

### 2.1 数据与状态

- 新增独立 Django `rehearsal` 业务域，所有数据按 `workspace_id` 隔离。
- 预演场景和申告模板带编号、版本、状态与配置快照。
- 预演实例支持“数据准备中 → 待启动 → 预演中 → 已完成”，并支持活动状态取消。
- 数据生成、数据导入和每次状态变化均写入只追加事件，不覆盖历史。
- 数据批次保存来源、版本、总数、有效数、异常数、时序范围和错误汇总。

### 2.2 申告模拟

- 内置公众客户、政企客户两套 V1 模板，分别覆盖客户分群、渠道、申告类别和内容模式。
- 可指定模板、条数、序列起点和分钟间隔生成 1～500 条确定性时序申告。
- 支持 UTF-8 CSV 人工导入，单批最多 1000 条、5 MB。
- 导入按行校验时间、客户类型、严重程度和必填字段；部分错误不会抹掉整批正确数据。
- 联系方式仅存脱敏值；未脱敏导入值被标记为异常并在保存前再次脱敏。
- 支持按实例、客户类型、严重程度、校验状态、来源、日期和关键词筛选，并导出当前结果。
- 提供 CSV 导入模板、申告数据导出和批次校验报告，均使用 UTF-8 BOM，并防护表格公式注入。

### 2.3 管理端

- 新增“运营治理 → 故障与场景预演”入口。
- 页面提供汇总指标、统一控制链、两类模板、实例列表和申告数据流。
- 实例抽屉内完成数据生成/导入、状态推进、批次查看、校验报告下载和审计轨迹查看。
- 页面与抽屉均显式设置滚动容器，在嵌套路由中可滚动到底。
- `http://localhost:3000/rehearsal` 可跳转到 `/admin/rehearsal`。
