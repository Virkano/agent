# 处置进度模拟 M10-02 验收文档

## 1. 验收结论

P0-06 / M10-02 已完成，建设方案功能对比表 X19“增加处置进度模拟能力 / 增加动态流程模拟引擎”形成可运行、可演示、可追溯的粗粒度 V1。

本次复用 M10-01 的工作空间、预演实例、申告数据和追加事件底座，补齐“选择流程模板 → 生成运行快照 → 启动并推进 → 阻塞/恢复/结束 → 查询与导出”的动态处置闭环。

## 2. 交付范围

### 2.1 流程模板与运行数据

- 新增处置流程模板、流程运行、流程步骤和流程事件四类数据模型，全部按 `workspace_id` 隔离。
- 内置公众客户 4 步人工流程和政企客户 5 步自动流程；支持后端创建自定义版本化流程模板。
- 生成流程时固化模板编号、名称、版本和完整步骤快照，历史运行不受模板后续修改影响。
- 同一请求编号幂等返回已有流程，不重复生成步骤和事件。
- 只有待启动或预演中的实例，并且至少存在一条有效申告时，才允许生成处置流程。

### 2.2 动态流程引擎

- 支持待执行、执行中、已阻塞、已完成、已取消和执行失败六种流程状态。
- 支持启动、完成当前步骤、自动推进、阻塞、恢复、跳过、失败和取消八类动作。
- 阻塞必须填写原因；手工流程不能调用自动推进；终态流程不能继续操作。
- 步骤保存开始时间、完成时间、实际耗时和操作备注，运行主表实时汇总完成步数、总步数、进度与状态分布。
- 每次动作写入只追加流程事件，包含前后状态、关联步骤、操作者、说明和原因。

### 2.3 管理端与导出

- “故障与场景预演”页面增加处置进度模拟区域，展示流程数量、执行中/阻塞数量和两套默认模板。
- 支持按预演实例、流程模板、状态和关键词筛选，提供分页和当前筛选结果 CSV 导出。
- 实例抽屉可选择模板、设置流程名称和推进方式并生成流程；流程抽屉可查看步骤、进度、阻塞原因和审计事件，并按当前状态显示可执行动作。
- 页面、实例抽屉和流程抽屉均使用独立滚动容器，适配父级 `overflow: hidden` 的嵌套路由。
- 页面与 CSV 均显示快照中的中文步骤名称，不暴露内部步骤代码；CSV 使用 UTF-8 BOM 并防护公式注入。

## 7. 已知边界与下一步

- 当前自定义流程模板由后端接口支持，页面先展示并使用两套内置模板；高级可视化编排器属于后续优化，不阻塞 X19 粗粒度闭环。
