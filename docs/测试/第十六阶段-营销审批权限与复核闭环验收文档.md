# 第十六阶段：营销审批权限与复核闭环验收文档

## 目标

将触达批次审批升级为可执行的权限与复核流程，防止创建人自审，并让每次审批决定和重提修改都可追溯。

## 权限规则

- 审批人：系统管理员或当前工作空间的“工作空间管理员”。该角色在营销流程中承担营销主管/审批人职责。
- 创建人不能审批自己创建的批次，即使同时拥有管理员角色。
- 只有待审批批次可审批；只有被驳回且尚未执行的批次可由创建人修改后重提。
- 驳回必须填写原因；重新提交必须填写修改说明。

## 页面操作

1. 创建触达批次后，状态为“待审批”。创建人看到“待主管审批”，不能执行。
2. 使用另一个工作空间管理员账号进入同一任务，在批次操作列点击“审批”。
3. 选择“驳回”并填写原因。批次变为“已驳回”。
4. 创建人点击“修改重提”，调整客户状态、套餐、省份、流量/通话门槛或冷却期，填写修改说明并提交。
5. 批次重新生成筛选快照并回到“待审批”；主管审批通过后，执行入口恢复可用。
6. 在“执行”抽屉查看“审批留痕”，应按时间展示提交、驳回、重提、通过及对应操作人和意见。

## 验收结果

- 数据库迁移 `marketing.0007_marketingtouchbatchapprovalrecord` 已应用。
- 双账号自动化验收通过：创建人自审被 403 拦截；主管可驳回；创建人可重提；主管可通过。
- 留痕动作顺序验证通过：`SUBMITTED → REJECTED → RESUBMITTED → APPROVED`。
- 前端类型检查与 ESLint 检查通过。

## 边界说明

审批角色沿用现有工作空间管理员，管理员可在系统角色管理中配置。后续若需多级会签、指定审批人或超时自动升级，可在此留痕模型之上增加审批流节点。
