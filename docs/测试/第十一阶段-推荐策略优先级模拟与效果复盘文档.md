# 第十一阶段：推荐策略优先级、模拟与效果复盘

## 本阶段交付

在营销推荐策略基础上增加安全运营能力：

- **优先级**：数字越小越优先；多个活动命中时只选择最高优先级活动；
- **生效日期**：支持开始与结束日期，过期活动不会命中；
- **互斥组**：同一互斥组不允许使用相同优先级，避免出现不可解释的平级命中；
- **保存校验**：启用策略时必须有活动、客户可见权益、费用边界和合约边界；校验活动名称、优先级和日期范围；
- **客户画像模拟**：在场景页用与真实会话同一套后端规则预览命中结果，不创建会话、不修改客户数据；
- **策略效果复盘**：任务复盘按实际会话中的活动 ID 统计会话数、消息数、意向数和人工处理数。

每次新会话都把当时匹配的活动、优先级写入会话来源。因此之后调整活动，不会改写历史对话的命中依据。

## 配置步骤

1. 进入 **营销场景**（`/admin/marketing-scenario`），编辑目标场景。
2. 在“营销推荐策略”的每个活动中填写：
   - **优先级**：建议 10、20、30 递增；
   - **互斥组**：同一类活动填写同一个组名，例如 `199套餐升级`；
   - **生效日期**：临时活动填写起止日期，长期活动留空。
3. 保存。保存失败时按提示修正冲突或缺失的客户可见边界。

## 模拟步骤

1. 在目标场景右侧点击 **模拟**。
2. 输入当前套餐、省份、近月流量、近月通话。
3. 点击 **开始模拟**：
   - 命中时显示活动名称和优先级；
   - 不命中时显示“未命中任何有效活动”。
4. 修改套餐、省份或用量后再模拟，确认边界符合预期。

## 复盘步骤

1. 进入 **营销任务**，点击任务右侧 **复盘**。
2. 在“推荐策略效果”表查看每个活动的会话、消息、意向和人工处理数。
3. 使用这些数据调整活动优先级、适用条件或客户可见权益；不要仅依据模型回答判断活动效果。
