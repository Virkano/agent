# 第十阶段：营销推荐策略引擎操作与验收文档

## 本阶段交付

营销场景新增“营销推荐策略”，将原本只存在于知识库或提示词里的活动条件结构化配置，并在客户打开营销任务专属对话时进行匹配。

策略包含：

- 活动名称与客户可见权益；
- 适用套餐关键词、省份、最低流量、最低通话条件；
- 客户可见的费用边界和合约边界。

知识库仍负责政策依据，智能体仍完成多轮对话。本功能只在客户命中管理员已配置活动时，使用该活动生成确定的客户可见建议；价格、合约或未命中活动时不会编造办理资格与金额。

## 配置步骤

1. 进入 **营销场景**（`/admin/marketing-scenario`），编辑需要使用的场景。
2. 在 **营销推荐策略** 区域打开“启用推荐策略”。
3. 点击“新增活动”或填写默认活动，至少配置：
   - 活动名称；
   - 客户可见权益；
   - 适用当前套餐关键词；
   - 费用边界、合约边界。
4. 可按实际政策补充适用省份、最低近月流量、最低近月通话。
5. 保存场景。之后通过该场景创建/已有的营销任务会在客户打开新会话时读取最新策略。

## 验证流程

1. 在 **营销任务 → 客户** 中，选择一个满足策略条件的客户并点击“测试”。
2. 新建对话，输入：`我流量经常不够，推荐什么套餐？`。
3. 客户应看到活动名称、权益、费用边界、合约边界；不应出现坐席话术、客户画像、内部规则等内部信息。
4. 再输入：`这个活动会额外收费吗？`。
5. 系统不得承诺固定费用，应提示以当地实际可办理方案为准，并在办理前确认月费、优惠期限和合约期。
6. 使用不满足套餐、省份或用量条件的客户测试时，不应展示不匹配活动。

## 实现边界

- 策略按配置顺序取第一个满足条件的活动；如多活动需设置优先级，应在下一阶段扩展显式优先级与互斥规则。
- 每个新会话将本次匹配结果写入会话来源，后续调整场景配置不会篡改历史会话的推荐依据。
- 投诉、退订、具体办理和账单争议仍由人工确认，不由策略引擎直接办理。
