# 自动训练流水线 M08-02 验收文档

## 1. 验收结论

M08-02 已完成粗粒度 V1：模型生命周期新增特征处理、训练、评估、审批、部署和定时重训流水线，执行过程可追踪、失败可重试、人工审批可通过或拒绝，并能自动注册和发布模型版本。

## 2. 已实现范围

- 流水线配置：注册模型、数据集、训练参数、评估指标、准入阈值、审批模式和部署策略。
- 任务状态机：`PENDING → RUNNING → WAITING_APPROVAL/SUCCESS/FAILED/REJECTED`。
- 阶段记录：特征、训练、评估、审批、部署五个阶段分别保存状态、输入、输出、错误和时间。
- 自动发布：评估通过且自动审批时，自动完成版本发布；人工模式等待用户审批。
- 定时重训：支持标准五段 Cron 表达式，调度器每分钟扫描到期流水线。
- 失败处理：评估不达标会终止发布并跳过后续阶段；失败或拒绝记录支持重试。
- 扩展边界：当前使用本地确定性训练执行器，后续可替换真实训练平台或 MLflow Project。
