# 第九阶段：营销客户意向与人工跟进测试文档

## 本阶段交付

将“客户可以与营销智能体对话”补成可运营闭环：

- 客户每次在营销任务专属链接中发言后，系统基于客户原话自动沉淀状态、意向和异议；
- 坐席可独立记录人工跟进结果和跟进说明；
- 任务复盘展示意向率、人工跟进次数、自动沉淀客户数和主要异议。

自动分析不调用小参数模型，不会把模型猜测当作客户事实。客户原有“备注”不会被自动覆盖，人工标为“转人工”后，后续普通对话也不会把该状态改回去。

## 操作流程

1. 进入 **营销任务**（地址为 `/admin/marketing-task`），在目标任务右侧点击 **客户**。
2. 在客户行点击 **测试**，新建会话后以客户身份发送一句真实诉求，例如：`我先考虑一下，费用有点贵。`
3. 返回客户名单并刷新：该客户应变为 **已咨询**，意向/异议显示为 `待跟进 · 费用`。
4. 如需坐席处理，在同一客户行点击 **跟进**，选择跟进结果、填写意向标签和跟进记录后保存。
5. 返回任务主列表点击 **复盘**：查看“意向率”“已记录人工跟进”“自动沉淀客户数”和“主要异议”。

## 状态规则

| 客户原话信号 | 自动状态 | 意向标签 |
| --- | --- | --- |
| `帮我办理`、`我要升级`、`可以办理` | 有意向 | 明确办理意向 |
| `不需要`、`不想`、`不办` | 无意向 | 明确无意向 |
| `人工`、`投诉`、`退订`、`账单`、`扣费` | 转人工 | 需人工跟进 |
| 其他咨询 | 已咨询 | 已咨询；包含费用/合约/流量/服务问题时为待跟进 |

费用、合约、流量和服务会作为可复盘的异议标签。规则用于分流和统计，不代表最终业务判定；涉及具体资费、办理、投诉、退订等事项仍应按现网政策由人工确认。
