# 数据模拟与趋势看板 M10-03 验收文档

## 1. 建设范围

P0-06 / M10-03 已完成，建设方案功能对比表 X20“增加数据模拟能力 / 增加自定义模拟数据构造、看板”形成可运行、可演示、可导出的粗粒度 V1。

本步复用 M10-01 的预演实例与追加式事件，增加：

- 指标趋势和舆情趋势两类版本化模板。
- 自定义字段编号、名称、单位、数值范围、起止值、精度与分布规则。
- 线性、周期波动、随机与阶跃四种数据构造方式。
- 批次幂等、规则快照、业务标签、时序点和预演事件留痕。
- 批次筛选、详情、趋势图、最新/平均/最小/最大/净变化统计与 CSV 导出。

## 2. 数据模型与规则

新增 `RehearsalDataTemplate`、`RehearsalDataBatch` 和 `RehearsalDataPoint` 三层模型。批次保存模板版本、生成规则快照、标签和汇总；时序点保存发生时间、多字段值、动态标签与模拟说明。

默认模板：

| 模板 | 类型 | 默认字段 |
| --- | --- | --- |
| `NETWORK-METRIC-V1` | 指标趋势 | 网络负载、平均时延、告警数量 |
| `SENTIMENT-TREND-V1` | 舆情趋势 | 舆情声量、情感得分、负向占比 |

模拟数值使用批次请求和字段规则构造稳定随机种子：同一幂等请求不重复生成，已保存批次可重现和导出，不将随机数据宣称为真实网管或舆情采集结果。

## 3. 管理接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/data-template` | 新建自定义数据模板 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/instance/{instance_id}/data-simulation` | 生成模拟数据批次 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/data-simulation` | 按实例、模板、类型、状态、标签、时间或关键词筛选 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/data-simulation/{batch_id}` | 查看规则快照、汇总和全部时序点 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/data-simulation/export` | 导出当前筛选或单个批次 |
