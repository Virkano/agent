# 双塔召回模型 M07-01 验收文档

## 一、验收范围

M07-01 对应建设方案 X01，完成粗粒度 V1：

- 从营销客户生成用户塔特征快照，从已上线且审批通过的营销活动生成物料塔特征快照。
- 使用 PyTorch 训练 `hashed-linear-two-tower-v1` 轻量双塔，不以现有规则优先级模拟模型召回。
- 保存训练任务、模型参数、训练指标和模型版本；发布新版本时归档旧版本。
- 为每个活动生成独立物料向量，在线推理时计算用户向量并输出 TopK、分数与解释特征。
- 保存每次推理的客户特征快照、候选结果、模型版本和耗时。
