# 知识库检索评估中心验收

## 交付结论

知识库详情已新增“检索评估”入口，形成从评估样本、CSV 批量维护、批量执行、指标对比、失败诊断、历史追溯到结果导出的完整闭环。功能已完成数据库迁移、自动化回归、真实模型健康检查和真实检索链路验证。

## 功能范围

- 评估问题集：支持问题、期望文档、期望段落、期望答案、启用状态、编辑删除、CSV 模板下载、批量导入和样本导出。
- 导入保护：支持 UTF-8/GB18030、2MB/500 行限制、重复问题跳过、文档/段落名称校验和整批原子失败。
- 目标校验：期望文档和段落必须属于当前工作空间的当前知识库。
- 多链路对比：向量检索、关键词检索、混合检索、混合检索加重排。
- 执行参数：Top K、最低相似度和可选重排模型。
- 指标：命中率、Recall@K、MRR、无答案率、失败数和平均耗时。
- 失败隔离：单个样本或模式失败时保留其他结果，并标记为部分成功或失败。
- 结果追溯：保存问题和期望目标快照，删除评估样本后历史结果仍可查看。
- 依赖健康：向量索引数量、向量模型实际调用、Ollama 服务和已加载模型。
- 历史与导出：最近执行列表、逐条召回详情和 UTF-8 BOM CSV 下载。
- 权限与隔离：复用知识库命中测试/编辑权限组合，所有数据按工作空间和知识库双重过滤。

## 操作入口

进入任一工作空间知识库详情，在左侧子菜单选择“检索评估”。少量样本可直接新增；批量验收时先下载 CSV 模板，按知识库中的文档名和段落标题填写后批量导入。重复问题会跳过，任一非重复行目标无效时整批不写入。至少存在一个启用样本后即可运行评估；需要重排模式时必须先配置可用的重排模型。
