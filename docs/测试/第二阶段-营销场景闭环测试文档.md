## 3. 营销场景内容

场景主题：存量客户 5G 套餐升级推荐。

核心知识：

- 目标客群：近 3 个月月均流量使用超过当前套餐 80%，且尚未办理 5G 升级包的在网客户。
- 推荐策略：先说明客户近期流量使用趋势，再推荐 129 元 5G 畅享升级包；客户关注价格时提示首月体验优惠和到期提醒。
- 合规要求：不得承诺未配置的永久折扣；不得收集身份证、银行卡完整号等敏感信息；客户明确拒绝后停止营销。
- 转人工条件：客户投诉、要求退订、涉及账单争议或连续两次表达不满时转人工客服。

## 6. 本次发现并修复的问题

问题：知识库分页列表在未显式传 `folder_id`，或前端传入空字符串 `folder_id=` 时，会把空值当成具体文件夹 ID 校验，导致返回业务 `code=500`，错误信息为“文件夹不存在”。

修复：在 `apps/knowledge/serializers/knowledge.py` 中将空 `folder_id` 统一归一为当前工作空间根目录，同时查询条件只在 `folder_id` 有真实值时才追加文件夹过滤。

影响范围：这是通用修复，对所有工作空间生效，不是针对“营销闭环测试”样例的硬编码。
