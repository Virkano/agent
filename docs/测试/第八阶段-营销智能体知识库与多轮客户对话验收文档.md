# 第八阶段：营销智能体、知识库与多轮客户对话验收

## 目标

验证客户从“营销任务 → 影响客户名单 → 对话”进入后，系统真实执行知识库检索、模型生成和多轮上下文承接；客户窗口不展示运营内部话术或规则。

## 已实现链路

1. 打开客户对话时，携带营销任务 ID 和客户 ID。
2. 系统将客户套餐、近月流量、通话等信息作为系统上下文，不混入客户提问。
3. 每轮先按客户当前问题检索已关联知识库，再将命中段落、系统上下文和最近 3 轮历史交给本地模型。
4. 费用类问题在模型输出后经过客户合规校验：不能承诺“必然加钱”“完全免费”等未被政策确认的结论。
5. 客户窗口只显示客户可见回复；无真实段落时不显示“引用分段 0”。

## 操作步骤

1. 进入“营销任务”，打开“存量客户套餐升级首轮触达任务”。
2. 点击“影响客户名单”，选择“张女士”，点击“打开对话”。
3. 发送：`我流量经常不够，升级会不会有额外费用？`
4. 在同一会话继续发送：`那贵不贵？`

## 期望结果

第一轮应表达费用需以当地可办方案为准，并说明办理前确认月费变化、优惠期限和合约期；不得承诺具体金额。

第二轮应承接第一轮，解释是否划算取决于当地方案和月费变化，不能重复开场、复述内部流程或把客户反问原样返回。

回复中不得出现：`建议坐席话术`、`转人工条件`、`内部规则`、`客户画像`、`检索`、`提示词`、`MySQL`、`数据库`。

## 注意事项

- 已存在的历史消息不会自动改写；请新建对话后验证新链路。
- 当前本地模型为 `deepseek-r1:1.5b`。它已可通过合规校验稳定完成本场景；若后续增加复杂营销话术或精细推荐，建议替换为能力更强的本地模型后再做回归测试。
