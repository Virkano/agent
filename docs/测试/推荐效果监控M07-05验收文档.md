# 推荐效果监控 M07-05 验收文档

## 1. 验收范围

M07-05 对应建设方案 X05，在双塔召回、多路融合、可解释精排和反馈增量链路上补齐推荐效果监控粗粒度 V1：

- 支持最近 7、30、90 天观察窗口。
- 统计曝光、点击、转化和负反馈漏斗，以及 CTR、CVR 和负反馈率。
- 统计有效营销物料覆盖率，并基于物料地域与套餐关键词计算列表多样性。
- 聚合融合召回、精排和端到端平均耗时，以及端到端 P95 耗时。
- 按日期、精排版本和营销物料展示表现，所有结果均来自运行记录和反馈事件。
- 前端将效果监控纳入“召回与精排引擎”统一页面，不新增重复菜单或通知中心。

## 2. 指标口径

- CTR：点击数 / 曝光数。
- CVR：转化数 / 曝光数。
- 负反馈率：负反馈数 / 曝光数。
- 覆盖率：窗口内被曝光的去重物料数 / 当前已上线且审批通过的物料数。
- 多样性：单次精排结果内，各物料“地域 + 套餐关键词”标签集合两两 Jaccard 距离的平均值，再对窗口内精排运行取平均。
- 端到端耗时：关联融合运行耗时 + 精排耗时；展示平均值和 P95。

当前指标用于粗粒度 V1 的同口径观察，不替代生产埋点平台、实验显著性检验或实时流计算。

## 3. 接口与页面

- `GET /admin/api/workspace/{workspace_id}/marketing/recommendation/effect-dashboard?days=7|30|90`
- 页面：`/admin/recommendation-engine` → “效果监控”页签。
- 返回内容：时间窗口、汇总指标、耗时、漏斗、每日趋势、版本表现和物料表现。

本阶段直接聚合 `RecommendationRankingRun`、`RecommendationFusionRun`、`RecommendationFeedbackEvent` 与 `MarketingCampaign`，没有新增数据表，因此不存在新增迁移。

## 7. V1 边界与下一步

- 当前效果聚合按请求实时读取数据库，适合本地样例和粗粒度演示；大数据量下应改为预聚合指标表或流式指标服务。
- 当前版本表现按反馈关联的精排版本归集，未实现实验分流、置信区间和显著性分析。
- 覆盖与多样性使用当前物料目录和标签，后续可增加类目层级、去流行度偏置和业务价值权重。
- M07 / X01～X05 至此形成“训练 → 发布 → 召回 → 融合 → 精排 → 反馈 → 增量版本 → 效果监控”的完整粗粒度 V1。
- 下一步进入 M09-01 / X09，建设 IVR 协议模拟、会话与变更操作事件的最小闭环。
