# 场景动态回溯 M10-12 验收文档

## 1. 验收范围

对应建设方案 X29“场景动态回溯”。本任务复用 X28 已应用到预演实例的故障配置和拓扑快照，把能力调用、模拟告警及可选场景执行转换为有序流量帧，形成故障前后拓扑、节点级轨迹和镜像差异的不可变证据。

粗粒度 V1 边界：X25“数据动态回溯”面向指标、告警、操作、申告和舆情的统一业务时间线；X29 面向网络流量、拓扑和节点状态变化，两者保留独立快照，不用后生成结果覆盖历史。当前回放使用预演事实和保存的拓扑契约，不接入真实设备抓包或生产网管流量。

## 2. 已交付能力

- 只有已绑定含拓扑快照故障配置的预演实例才能生成场景回放，避免无拓扑基线的伪镜像。
- 能力调用、模拟告警及关联场景执行按时间排序为流量、告警和控制三类帧，保存来源、目标节点、协议、状态、耗时和源事实引用。
- 根据失败、超时、活动告警和失败场景推导节点状态，生成完整 `topology_before` 与 `topology_after` 快照。
- 对每个节点保存前后状态、经过帧、关注帧和变化标识；对链路保存前后状态差异。
- 一次生成同时固化流量帧、前后拓扑、节点轨迹、镜像差异和统计摘要，并计算 64 位 SHA-256 校验值。
- 请求幂等键在工作空间内唯一，重放相同请求返回原镜像，不重复写历史。
- 列表支持实例、场景执行、状态、节点编号和关键字筛选，并返回可回放数、空镜像数、帧数、变化节点和平均耗时汇总。
- 管理端提供播放/暂停、前后帧、时间滑杆、前后拓扑镜像、节点轨迹、筛选列表、新建抽屉和完整证据抽屉。
- 实例详情和预演 dashboard 同步展示回放数量、可回放数量和流量帧总数。

## 3. 数据模型与迁移

迁移：`apps/rehearsal/migrations/0011_rehearsalscenereplay.py`。

`RehearsalSceneReplay` 保存工作空间、预演实例、可选场景执行、故障配置、请求幂等键、回放窗口、流量帧、前后拓扑、节点轨迹、镜像差异、汇总、生成时间和 SHA-256 校验值。

状态为：

- `READY`：存在可回放事实。
- `EMPTY`：窗口内无流量事实，但仍保留空镜像作为审计证据。

## 8. 手工测试方法

1. 打开“故障与场景预演”，先确认实例已应用 X28 故障配置且拓扑有节点。
2. 在“场景动态回溯”点击“生成场景回溯”，选择实例；需要限定事实范围时选择场景执行或填写起止时间。
3. 生成后点击播放，观察帧编号、链路、协议、状态和耗时是否随时间滑杆更新。
4. 点击前后拓扑节点，核对节点轨迹中的前后状态、经过帧和关注帧。
5. 打开详情，核对 SHA-256、节点/链路差异及流量台账；使用实例、状态、节点或关键字验证筛选。
