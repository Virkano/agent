# 第二十阶段：营销客户名单导入验收文档

## 目标

让运营人员能够将客户名单导入到指定营销任务，并在入库前完成字段映射、格式校验和重复识别。导入后的客户可直接进入既有的触达批次、审批、执行和转化闭环。

## 功能范围

- 支持 CSV、XLSX 文件，单次最多 1,000 行、5MB。
- 自动识别常用中英文表头；可在页面中手工调整字段映射。
- `手机号/客户标识` 为必填；客户名称、省份、套餐、流量、通话、初始意向和备注可选。
- 校验后展示每行状态：可导入、重复跳过、格式错误。
- 以“当前营销任务 + 客户标识”为范围去重，同时识别同一文件中的重复行。
- 确认导入后仅新增“待触达”客户；不覆盖已有客户的状态、跟进记录、批次快照或转化历史。
- 保存导入文件名、操作人、字段映射、数量统计和最多 100 条异常行摘要，最近记录可在导入窗口查看。

## 页面操作

1. 进入“营销任务”，打开目标任务的“客户”。
2. 点击“导入名单”，可先下载 CSV 模板。
3. 选择 CSV 或 XLSX 文件，点击“校验并预览”。
4. 检查自动识别的字段映射；若表头不规范，在下拉框中调整后再次点击“校验并预览”。
5. 只要存在“可导入”数据，点击“确认导入”。
6. 关闭窗口后刷新客户列表；新客户的初始状态应为“待触达”。随后可按既有流程生成触达批次并提交审批。

## 推荐表头

`客户名称, 手机号, 省份, 当前套餐, 近月流量, 近月通话, 初始意向, 备注`

其中“手机号”列也可以放客户 ID；不同业务系统表头可通过手工映射适配，不需要修改代码。

## 边界说明

- 本阶段是“文件接入”能力，不会主动连接 CRM、计费或工单系统；外部 API 增量同步将作为后续独立阶段。
- 客户标识的去重范围仅限当前工作空间的当前营销任务，避免影响其他任务的名单运营。
- 由于导入文件可能含个人信息，系统不保存原始文件内容；只保存必要的操作留痕和异常摘要。
