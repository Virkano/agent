# 故障模拟配置 M10-11 验收文档

## 1. 验收范围

对应建设方案 X28“故障模拟配置”。本任务在统一预演实例之上补齐告警规则、超时策略、运行时段、拓扑快照、应急预案和场景关联，使故障配置可以版本化、校验、复核并以不可变快照绑定到预演实例。

粗粒度 V1 边界：当前配置负责描述和约束故障模拟，不直接调度真实网络设备，也不新增模块内通知中心；告警通知继续使用平台右上角全局告警铃铛。

## 2. 已交付能力

- 工作空间级版本化故障配置，同一 `code` 按版本递增，并保留来源版本。
- 同一版本保存告警规则、超时策略、运行时段、拓扑节点/链路和应急预案步骤五类快照。
- 自动执行五项门禁校验：告警字段及比较符、步骤/整体超时范围、时段/星期/时区、拓扑节点唯一与链路端点、预案及步骤完整性。
- 校验通过进入“可应用”，失败保留“待校验”及逐项错误；支持人工复核、版本克隆和归档。
- 配置与预演场景绑定，只能应用到同场景且未进入终态的预演实例。
- 应用时同时保存配置外键和不可变配置快照；后续归档配置不影响实例历史事实。
- 创建、校验、克隆、应用和归档均写追加式配置事件；实例侧同步写“应用故障模拟配置”事件。
- 管理端提供故障矩阵、版本轨道、拓扑蓝图、策略摘要、绑定操作、筛选分页、新建抽屉和详情审计抽屉。

## 3. 数据模型与迁移

迁移：`apps/rehearsal/migrations/0010_rehearsalinstance_fault_configuration_snapshot_and_more.py`。

- `RehearsalFaultConfiguration`：保存工作空间、场景、来源版本、五类配置、校验报告和发布状态。
- `RehearsalFaultConfigurationEvent`：保存配置的不可覆盖操作事实，可关联具体预演实例。
- `RehearsalInstance`：新增当前故障配置关联和 `fault_configuration_snapshot` 不可变快照。
- `RehearsalInstanceEvent`：新增 `FAULT_CONFIG_APPLIED` 事件类型。

状态为 `DRAFT / READY / ARCHIVED`，配置事件为 `CREATED / VALIDATED / CLONED / APPLIED / ARCHIVED`。

## 4. 接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET / POST | `/admin/api/workspace/{workspace_id}/rehearsal/fault-configuration` | 查询或创建故障配置 |
| GET | `/admin/api/workspace/{workspace_id}/rehearsal/fault-configuration/{configuration_id}` | 查看配置、绑定实例和审计事件 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/fault-configuration/{configuration_id}/clone` | 克隆新版本并自动校验 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/fault-configuration/{configuration_id}/validate` | 人工复核五项配置门禁 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/fault-configuration/{configuration_id}/archive` | 归档配置版本 |
| POST | `/admin/api/workspace/{workspace_id}/rehearsal/instance/{instance_id}/fault-configuration` | 将可应用配置快照绑定到实例 |

列表支持场景、状态、是否绑定和关键字筛选，并返回可应用、待校验、已归档及绑定实例汇总。
