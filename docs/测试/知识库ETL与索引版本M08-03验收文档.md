# 知识库 ETL 与索引版本 M08-03 验收文档

## 1. 验收结论

M08-03 已完成 X34 粗粒度 V1：知识库可以选择一份或多份启用文档执行 ETL 产物核验，完整记录解析、清洗、切分、向量化、质量门禁和索引版本六个阶段；质量通过后生成候选版本，可发布为线上版本，也可回滚到历史版本，所有切换均保留审计记录。

本阶段复用项目已有的文档解析、段落和向量数据，不重复实现文件解析器。ETL 运行负责固定处理范围、核验真实产物、执行准入门禁并形成可追溯版本。

## 2. 已实现范围

- ETL 运行：支持全部启用文档或指定文档批量运行，固定文档 ID 和质量配置快照。
- 六阶段追踪：每阶段保存顺序、状态、输入、输出、错误、开始和完成时间。
- 质量门禁：至少校验有效段落数与段落向量覆盖率，阈值可在每次运行时配置。
- 失败重试：失败运行按原文档范围和阈值创建一条带来源关联的新运行，不覆盖历史记录。
- 索引版本：质量通过后生成递增版本，保存文档数、段落数、向量数、向量模型、质量结果和内容摘要。
- 发布切换：同一知识库只有一个线上版本；新版本发布时原线上版本转为历史版本。
- 历史回滚：历史版本可重新成为线上版本，记录来源版本、目标版本、原因、操作人和时间。
- 管理端页面：知识库详情新增“ETL 与索引版本”，包含指标、六阶段说明、运行列表、版本列表、发布审计、运行表单和阶段详情抽屉。
