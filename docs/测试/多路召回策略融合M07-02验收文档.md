# 多路召回策略融合 M07-02 验收文档

## 1. 验收范围

M07-02 对应建设方案 X02，完成多路召回策略融合粗粒度 V1：

- 在 M07-01 双塔召回之外补齐业务规则、协同过滤、内容相似、全局热度和地域召回。
- 六个通道分别召回候选，单通道分数归一化后按可配置权重融合。
- 同一营销活动跨通道只保留一条结果，并保留每个来源的通道分、权重、贡献值和解释。
- 融合配置与每次融合运行均持久化，支持结果追溯。
- 没有已发布双塔模型时自动降级为其余通道，不阻断规则类推荐。

## 2. 实现说明

### 2.1 六路召回

| 通道 | 粗粒度 V1 信号 |
| --- | --- |
| 双塔召回 | 使用已发布 `hashed-linear-two-tower-v1` 用户向量与物料向量相似度 |
| 业务规则 | 校验地域、套餐关键词、流量和通话门槛，并结合活动优先级 |
| 协同过滤 | 基于地域、套餐和意向相似客户的历史召回偏好 |
| 内容相似 | 用户画像文本与活动名称、权益、说明及关键词的字符特征相似度 |
| 全局热度 | 历史推荐曝光与已确认办理记录的加权热度 |
| 地域召回 | 精确覆盖客户省份或全国通用活动 |

融合公式为：

`融合分 = Σ(通道归一化分 × 通道权重) / 启用通道权重总和`

### 2.2 数据与接口

- 新增 `RecommendationFusionConfig`：工作空间级通道开关、权重和候选池配置。
- 新增 `RecommendationFusionRun`：客户、模型版本、配置快照、各路结果、融合结果和耗时。
- `GET/PUT /marketing/recommendation/fusion-config`
- `GET /marketing/recommendation/fusion-dashboard`
- `POST /marketing/recommendation/fusion-infer`

前端推荐引擎页新增“多路融合”“融合记录”和“融合配置”，M07-01 的双塔训练、版本、向量和单路推理入口继续保留。
