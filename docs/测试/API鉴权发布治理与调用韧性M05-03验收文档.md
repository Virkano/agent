# M05-03 API 鉴权、发布治理与调用韧性验收

日期：2026-09-21。范围：X10 粗粒度 V1 的鉴权证明门禁、发布治理和 Mock 调用韧性。

## 交付

- API Key、JWT、OAuth2、签名和 IP 白名单的配置与最小校验链路；调用上下文必须由可信上游标记为已验证，JWT/OAuth2 额外校验有效期与权限范围，签名额外校验有效性、时间窗和防重放标记。审计不保存凭证内容。
- 测试→灰度→生产发布门禁；生产版本要求 OpenAPI 快照、IP 白名单，网关配置要求 HTTPS，破坏性变更需要确认和变更单号。版本快照不可覆盖，启停与发布均追加治理事件。
- Mock 调用的超时、有限重试、失败阈值熔断及恢复窗口；审计记录状态、尝试次数、耗时和脱敏请求快照。
- 控制台可配置治理参数、查看版本和事件、执行重试恢复及启停演示。

## 验证

- Django `check`、迁移检查、Ruff 和 `tools.test_api_orchestration` 8 项测试通过；迁移 `0011_api_orchestration_governance` 已应用开发库。
- 前端目标文件 ESLint、`pnpm run type-check`、`pnpm run build` 通过。
- 浏览器打开 `/admin/integration-orchestration` 无控制台错误。重试恢复新增成功审计，其脱敏快照显示 `attempts: 2`；停用、重新启用各新增一条治理事件，最终资产保持启用。详情抽屉已滚动到底并核对事件。验收截图：[治理事件](../../output/playwright/m05-03/m05-03-governance.png)。
- 原有 API Key、Schema 失败及版本回滚样例由 M05-01/M05-02 验收保留；本次自动化另覆盖环境门禁、鉴权失效、重试耗尽和熔断拒绝。

## 边界与后续

“已验证”是可信上游传入的证明上下文，当前模块不校验真实 API Key/JWT/OAuth2 凭证或签名的密码学有效性；不能把演示上下文当作生产认证。网关模式目前仅保存和校验地址/契约配置，调用仍为 Mock 回放，没有向真实晓搭网关发送请求。待获得真实网关地址、协议与密钥托管方案后，补充真实注册、调用、返回转换和联调验收。
