# 第十四阶段：任务经营看板与逾期预警验收文档

## 交付与使用

在“营销任务”列表中点击“看板”，可查看任务级汇总：客户漏斗、批次总数、执行中/待执行、逾期批次、已记录执行客户、批次进度，以及按“转人工、意向、已咨询、待触达”排序的优先客户。

批次截止时间早于当前时间且未关闭时，会在看板中标记为“已逾期”。看板只做汇总和预警，不会自动向客户发送任何内容。

## 验收

- `GET .../marketing/task/{task_id}/dashboard`：HTTP 200。
- 样例任务返回客户 3 名、批次 2 个、优先客户 3 名。
- 前端 `vue-tsc`、后端 Ruff、Django `check` 均通过。
