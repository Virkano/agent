# IVR 协议模拟 M09-01 验收文档

## 1. 验收范围

M09-01 对应建设方案 X09 的通信入口与会话事件基础，完成粗粒度最小闭环：

- HTTP 协议接口可创建和查询 IVR 会话、接收音频分片契约及外部状态事件。
- WebSocket 使用与未来生产端一致的 JSON 消息契约回放，明确标记为 `CONTRACT_REPLAY`，不声称真实长连接已接通。
- 音频分片通过文本提示模拟 STT，生成 `PLAY_TEXT` 或 `TRANSFER_TO_AGENT` 响应指令与 TTS 文本。
- PostgreSQL 保存顺序化审计事件，Redis 保存当前会话快照；缓存异常不影响数据库事实链。
- 来电号码仅保存脱敏结果，不保存原号码或音频二进制。
- 管理端提供会话创建、协议边界、最近会话、状态回放和事件时间线。

## 2. 页面与接口

- 页面：`/admin/ivr-simulator`
- 本地简写入口：`/ivr-simulator`，Vite 自动跳转到标准 `/admin` 路径。
- 仪表盘：`GET /admin/api/workspace/{workspace_id}/marketing/ivr/dashboard`
- 协议说明：`GET /admin/api/workspace/{workspace_id}/marketing/ivr/protocol`
- 创建会话：`POST /admin/api/workspace/{workspace_id}/marketing/ivr/session`
- 会话详情：`GET /admin/api/workspace/{workspace_id}/marketing/ivr/session/{session_id}`
- 音频分片：`POST /admin/api/workspace/{workspace_id}/marketing/ivr/session/{session_id}/audio`
- 状态事件：`POST /admin/api/workspace/{workspace_id}/marketing/ivr/session/{session_id}/event`

响应事件按会话序号递增，带 `request_id` 的逻辑请求具备工作空间内幂等约束。外部可回放播报开始、播报结束、转人工、会话结束和失败事件。

## 6. V1 边界与下一步

- 当前未引入 Channels/Daphne 或生产 IVR 网关，因此 WebSocket 只做消息契约回放；真实长连接、电话线路、真实录音流和真实 STT/TTS 服务属于外部联调项。
- 当前模拟 STT 使用 `transcript_hint`，适合验证内部事件和响应协议，不等同于语音识别模型精度验收。
