# 项目目录说明

本文用于说明当前项目各目录的职责、是否属于源码、以及日常修改时通常应该从哪里进入。

## 顶层目录

| 目录/文件 | 作用 | 是否建议提交/保留 |
| --- | --- | --- |
| `apps/` | 后端 Django 主体源码，包含业务应用、公共组件、配置、路由、异步任务等。 | 保留，核心源码 |
| `ui/` | 前端 Vue 3 + Vite 项目，包含管理端和对话端两个入口。 | 保留，核心源码 |
| `docker/` | 自建 Docker 镜像与容器启动相关文件。当前项目 Docker 打包以这里为准。 | 保留 |
| `docs/` | 项目说明、部署说明、需求文档等 Markdown 文档。 | 保留 |
| `scripts/` | 本地开发辅助脚本，例如启动后端、前端、迁移等。 | 保留 |
| `main.py` | 后端服务控制入口，负责迁移、收集静态文件、启动 web/task/local_model 等服务。 | 保留 |
| `pyproject.toml` | Python 项目依赖、版本、构建与 Ruff 配置。 | 保留 |
| `README.md` | 项目基础说明。 | 保留 |
| `CLAUDE.md` | 给本地 AI 编码助手使用的项目约定、启动方式和架构说明。 | 保留 |
| `.env.local` | 本地开发环境变量，包含数据库、Redis、模型、运行目录等配置。 | 本地使用，按团队规则决定是否提交 |
| `.docker/` | 历史本地 Docker 运行数据目录；当前单业务镜像不在此管理 PostgreSQL/Redis 数据。 | 运行产物，不建议提交 |
| `.local_runtime/` | 本地运行时目录，保存日志、临时文件、配置、模型缓存等。 | 运行产物，不建议提交 |
| `data/` | 本地任务、检查工具或运行过程产生的数据。 | 运行产物，通常不提交 |
| `output/` | 本地测试、Playwright 截图或导出结果。 | 运行产物，通常不提交 |
| `Model catalog/` | 本地模型缓存目录。 | 运行产物，通常不提交 |
| `sentence-transformers/` | 本地 Sentence Transformers 模型缓存目录。 | 运行产物，通常不提交 |
| `shibing624/` | 本地中文向量模型缓存目录。 | 运行产物，通常不提交 |
| `telecom-ai-local-hash-embedding/` | 可选的本地模型缓存目录；当前默认 hash embedding 不依赖外部权重文件。 | 运行产物，通常不提交 |
| `.venv/` | Python 虚拟环境。 | 本地依赖目录，不提交 |
| `.ruff_cache/` | Ruff 缓存。 | 本地缓存，不提交 |
| `.playwright-cli/` | Playwright 本地工具缓存。 | 本地缓存，不提交 |
| `__pycache__/` | Python 字节码缓存。 | 缓存，不提交 |

## 后端目录 `apps/`

`apps/` 被加入 Python import path，Django 设置入口是 `telecom_ai_agent.settings`。

| 目录 | 作用 |
| --- | --- |
| `apps/telecom_ai_agent/` | Django 项目配置包，包含 settings、urls、wsgi/asgi、环境变量读取和全局常量。 |
| `apps/application/` | 智能体应用核心模块，管理应用配置、发布、会话流程、工作流、长期记忆、应用授权与运行管线。 |
| `apps/chat/` | 对话端相关模块，处理对话访问、对话用户、MCP 对话能力、聊天模板和聊天接口。 |
| `apps/knowledge/` | 知识库模块，处理知识库、文档、分段、向量化、检索、导入任务和知识库相关接口。 |
| `apps/models_provider/` | 模型供应商模块，管理 LLM、Embedding、语音等模型配置和不同厂商适配。 |
| `apps/local_model/` | 本地模型服务相关模块，主要用于本地模型下载、状态、配置和服务入口。 |
| `apps/tools/` | 工具模块，管理自定义工具、技能工具、MCP 工具、工作流工具、数据源工具等。 |
| `apps/trigger/` | 触发器模块，处理定时、事件或外部触发的任务配置与执行入口。 |
| `apps/users/` | 用户、角色、用户组、登录认证、权限关系等用户体系模块。 |
| `apps/system_manage/` | 系统管理模块，处理系统配置、平台展示配置、资源管理、授权等后台管理能力。 |
| `apps/homepage/` | 首页统计和后台概览相关接口。 |
| `apps/folders/` | 通用文件夹/资源目录能力，为应用、知识库、工具等资源提供树形目录支持。 |
| `apps/oss/` | 对象存储和文件访问相关模块。 |
| `apps/ops/` | 运维和异步任务支持，包含 Celery 相关逻辑。 |
| `apps/common/` | 后端公共基础库，包含认证、缓存、分段、配置、数据库、异常、字段、日志、中间件、工具函数等。 |
| `apps/xpack_lite/` | 扩展能力的轻量版模块，包含额外模型、序列化和视图逻辑。 |
| `apps/locales/` | 后端国际化语言包。 |
| `apps/static/` | Django 静态资源输出目录，主要承载前端构建后的 admin/chat 静态文件。 |

### 后端常见子目录约定

| 子目录 | 作用 |
| --- | --- |
| `api/` | API 路由注册或接口分组。 |
| `views/` | Django/DRF 视图层，处理请求入口和接口响应。 |
| `serializers/` | 请求参数、响应结构、对象序列化和校验。 |
| `models/` | 数据库模型定义。 |
| `migrations/` | Django 数据库迁移文件。 |
| `sql/` | 初始化或升级使用的 SQL 脚本。 |
| `task/` | 后台任务、文档处理任务或异步执行逻辑。 |
| `template/` | Prompt、导入模板或业务模板。 |

| 入口 | 作用 |
| --- | --- |
| `ui/admin.html` | 管理端入口，对应本地 `http://127.0.0.1:3000/admin/`。 |

## Docker 目录 `docker/`

当前项目已经不再使用旧的 `installer/` 路线，自建镜像相关文件集中在 `docker/`。根目录 `docker-compose.yml` 只定义一个 `app` 业务容器，不创建、拉取或删除 PostgreSQL/Redis 镜像。

| 文件 | 作用 |
| --- | --- |
| `docker/Dockerfile.app` | 唯一业务镜像 Dockerfile。先构建前端，再安装后端依赖，最终包含管理端、对话端、Django、Celery 和本地向量服务，仅声明 `8080/tcp`。 |
| `docker/start-app.sh` | 容器启动脚本，负责运行目录、外部 PostgreSQL/Redis 等待、迁移，以及 web/task/local_model 三类进程启动。 |
| `docker/.env.example` | 单业务容器配置样例，PostgreSQL、Redis 和 Ollama 均通过地址与凭证对接。 |
| `docker/initdb.sql` | 可提交的 PostgreSQL 安全初始化 SQL：幂等创建目标数据库并启用 pgvector，不删除已有库，不包含业务数据、账号、口令或密钥；业务表由容器启动时的 Django migrations 创建。该文件已排除在业务镜像之外。 |
| `docker/sandbox.c` | 工具执行沙箱源码，在 Linux 镜像构建阶段编译成 `sandbox.so`。 |

完整构建、SQL 导入、运行、导出/导入镜像和排障命令见 `docs/Docker手动打包与运行命令.md`。

## 本地开发脚本 `scripts/`

| 文件 | 作用 |
| --- | --- |
| `scripts/start-local.sh` | 本地启动脚本，支持 `web`、`celery`、`local_model`、`admin-ui`、`chat-ui`、`migrate`。 |

常用命令：

```bash
scripts/start-local.sh web
scripts/start-local.sh admin-ui
scripts/start-local.sh chat-ui
scripts/start-local.sh migrate
```

## 运行产物和缓存目录

这些目录通常由本地开发、Docker、模型下载、测试工具自动生成，不属于主要源码。

| 目录 | 作用 | 处理建议 |
| --- | --- | --- |
| `.docker/` | 历史本地 Docker 数据目录。 | 删除前仍需确认旧容器是否引用；当前业务 Compose 不依赖它。 |
| `.local_runtime/` | 本地日志、临时文件、配置和缓存。 | 可按需清理，但先确认没有正在运行的服务依赖。 |
| `data/` | Celery、检查工具或临时任务数据。 | 通常可清理，清理前确认用途。 |
| `output/` | 测试截图、导出物、临时输出。 | 通常可清理。 |
| `Model catalog/` | HuggingFace/模型缓存。 | 可重下，但删除会导致下次启动或使用模型变慢。 |
| `sentence-transformers/` | Sentence Transformers 模型缓存。 | 可重下。 |
| `shibing624/` | 中文向量模型缓存。 | 可重下。 |
| `.venv/` | Python 虚拟环境。 | 可重建，不提交。 |
| `ui/node_modules/` | 前端依赖。 | 可重装，不提交。 |
| `__pycache__/` | Python 缓存。 | 可清理，不提交。 |
| `.ruff_cache/` | Ruff 检查缓存。 | 可清理，不提交。 |
| `.playwright-cli/` | Playwright 工具缓存。 | 可清理，不提交。 |
